# 墨境 · 普通 VS Code 插件 0.13.1

0.13.1 使用 Shiki / TextMate 语法及 VS Code Light+/Dark+ 主题显示代码，未指定语言时自动识别或使用通用高亮，短代码不再退回无色文本。显式 text 保持纯文本。语法与渲染缓存不进入笔迹更新路径。

Inkspace 在普通 Microsoft VS Code 中提供手写与多介质画布，独立 Ink Engine 自动启动，保留 Raw Input 小数坐标与压力，Xournal++ 轮廓和 Cairo 渲染。无需修改 VS Code。只支持 Windows x64 桌面宿主。

界面按 [工作台 DESIGN](../docs/WORKBENCH-DESIGN.md) 实现：顶栏编排、画笔、橡皮、图形、插入、页面设置，右端控制属性栏；右栏在工具、单块、多选与资源上下文间切换。底栏左侧切换独立画布，右侧缩放和适合视图。图形模板放在右侧栏，默认在实际可见画布中心创建；也可拖动确定尺寸，两者共用 mxGraph。

所有介质使用 [公共悬浮条与介质框](../docs/MEDIA-FRAME-DESIGN.md)：普通悬停灰框和四边连线入口，选中后显示 26px 图标式悬浮条。正文或类型标签可拖动；图片、PDF、图形使用角柄等比缩放。文本只有排版宽度、小窗高度及独立字号，混合选区缩放中文字字号保持不变。控件固定屏幕大小。多选只有一套框与操作条。

鼠标默认编排、笔默认书写，工具分别记忆。属性栏选择配置设备；鼠标明确切换画笔、橡皮或图形绘制后直接绘制，无额外开关。中键始终临时平移；H 切换触控笔平移，再按 H 返回。P 画笔、E 橡皮、V 编排、T 文本，D / S 打开图形库。绘制穿透媒体控件，笔悬停不显示鼠标控件。

双击空白创建文本，双击 Markdown 进入对应段落的源码片段编辑；已有字符映射保留为辅助，复杂内容可切换完整源码。HTML 与 Markdown 共用文本块，右键更改类型；HTML 双击编辑完整源码。图片与 PDF 双击查看原稿，PDF 每页独立编排，更多菜单提供 PDF 原稿和文字操作。

编辑时周围渲染与画布位置保持不变，完整源码使用临时可滚动窗口；Tab / Shift+Tab 缩进，Enter 续写列表，Ctrl+Z / Ctrl+Y 使用文本本地历史。Ctrl+Enter 或“完成”一次提交；Esc 取消。空新建框取消不会写入文件。文本草稿与文档历史分离，未改动时保留原 CRLF。

Ctrl+F 搜索文本源码；Enter / Shift+Enter 跳转，Esc 关闭。Alt+← / Alt+→ 浏览之前位置、缩放及小窗滚动。底栏当前画布名打开 VS Code 列表，可新建、切换、重命名、排序及删除独立画布。普通滚轮平移，Shift+滚轮横移，Ctrl+滚轮缩放。

新笔记为 `.ink` 二进制增量格式，空 `.ink` 自动初始化，旧 `.inkspace.json` 兼容。停笔约 2 秒自动保存，持续编辑约 10 秒最多提交一次，Ctrl+S 立即保存。首次校准后同设备和显示配置自动恢复。安装和其他电脑分发见 [INSTALL](../docs/INSTALL.md)。

交互所有权由统一状态机与路由控制；媒体适配器提供内容能力，公共命令表供插入、悬浮条和右键复用。文本、PDF、图形移动不重建笔迹；缩放保留完整预览，Cairo 位图齐备后统一替换。代码与验证见 [交互规则](../docs/INTERACTION.md) 和 [检查记录](../docs/REVIEW.md)。

顶栏 ✦ AI 支持问答、解释、补充、整理与修改。0.13.0 按确认的设计收敛为对话与可选附件：默认不读取笔记，直接生成；“添加内容”选择选区或当前视野，默认只读数据，识别手写/图片/PDF 时显式附带画面。模型与请求详情在标题栏更多菜单，默认 Luna / low。修改先预览、一次撤销，旧提案不会覆盖新笔迹。画布 Markdown、HTML 和 AI 回答使用同一套代码高亮与复制入口。使用、运行条件和数据范围见 [AI 笔记助手](../docs/AI-NOTES.md)。
