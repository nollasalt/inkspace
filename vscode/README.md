# 墨境 · 普通 VS Code 插件 0.10.0

Inkspace 在普通 Microsoft VS Code 中提供手写与多介质画布，独立 Ink Engine 自动启动，保留 Raw Input 小数坐标与压力，Xournal++ 轮廓和 Cairo 渲染。无需修改 VS Code。只支持 Windows x64 桌面宿主。

界面按 [工作台 DESIGN](../docs/WORKBENCH-DESIGN.md) 实现：顶栏编排、画笔、橡皮、图形、插入、页面设置，右端控制属性栏；右栏在工具、单块、多选与资源上下文间切换。底栏左侧切换独立画布，右侧缩放和适合视图。图形模板放在右侧栏，默认在实际可见画布中心创建；也可拖动确定尺寸，两者共用 mxGraph。

所有介质使用 [公共悬浮条与介质框](../docs/MEDIA-FRAME-DESIGN.md)：普通悬停灰框和四边连线入口，选中后显示 26px 图标式悬浮条。正文或类型标签可拖动；图片、PDF、图形使用角柄等比缩放。文本只有排版宽度、小窗高度及独立字号，混合选区缩放中文字字号保持不变。控件固定屏幕大小。多选只有一套框与操作条。

鼠标默认编排、笔默认书写，工具分别记忆。属性栏选择配置设备；鼠标明确切换画笔、橡皮或图形绘制后直接绘制，无额外开关。中键始终临时平移；H 切换触控笔平移，再按 H 返回。P 画笔、E 橡皮、V 编排、T 文本，D / S 打开图形库。绘制穿透媒体控件，笔悬停不显示鼠标控件。

双击空白创建文本，双击 Markdown 进入对应段落的源码片段编辑；已有字符映射保留为辅助，复杂内容可切换完整源码。HTML 与 Markdown 共用文本块，右键更改类型；HTML 双击编辑完整源码。图片与 PDF 双击查看原稿，PDF 每页独立编排，更多菜单提供 PDF 原稿和文字操作。

编辑时周围渲染与画布位置保持不变，完整源码使用临时可滚动窗口；Tab / Shift+Tab 缩进，Enter 续写列表，Ctrl+Z / Ctrl+Y 使用文本本地历史。Ctrl+Enter 或“完成”一次提交；Esc 取消。空新建框取消不会写入文件。文本草稿与文档历史分离，未改动时保留原 CRLF。

Ctrl+F 搜索文本源码；Enter / Shift+Enter 跳转，Esc 关闭。Alt+← / Alt+→ 浏览之前位置、缩放及小窗滚动。底栏当前画布名打开 VS Code 列表，可新建、切换、重命名、排序及删除独立画布。普通滚轮平移，Shift+滚轮横移，Ctrl+滚轮缩放。

新笔记为 `.ink` 二进制增量格式，空 `.ink` 自动初始化，旧 `.inkspace.json` 兼容。停笔约 2 秒自动保存，持续编辑约 10 秒最多提交一次，Ctrl+S 立即保存。首次校准后同设备和显示配置自动恢复。安装和其他电脑分发见 [INSTALL](../docs/INSTALL.md)。

交互所有权由统一状态机与路由控制；媒体适配器提供内容能力，公共命令表供插入、悬浮条和右键复用。文本、PDF、图形移动不重建笔迹；缩放保留完整预览，Cairo 位图齐备后统一替换。代码与验证见 [交互规则](../docs/INTERACTION.md) 和 [检查记录](../docs/REVIEW.md)。

以下为保留的历史宿主实验说明，与当前普通 VS Code 插件安装方式无关。

## 原 VSCodium 集成版说明

# 墨境 · VSCodium 原生输入版 0.2.3

使用 VSCodium 的文件树、标签、Markdown 编辑器及保存/撤销机制；`.inkspace.json` 使用墨境无限画布打开。命令面板“墨境: 新建笔记”创建笔记，左侧墨境图标管理页面。鼠标框选、双击创建文本框，触控笔书写；支持粘贴图片/文字、公式及 PDF。

## 启动

运行 `Inkspace-VSCodium-0.2.3-Setup.exe`。安装程序内含 VSCodium、原生手写模块及 Inkspace 扩展，不需要另外安装 Node.js。默认安装到当前用户的本地程序目录，可选择安装路径、桌面快捷方式及文件夹右键入口。

开始菜单或桌面的 **Inkspace VSCodium** 打开工作区；资源管理器的文件夹及空白处右键可选择“在 Inkspace 中打开”。Windows 11 可能需先选择“显示更多选项”。打开文件夹后可直接访问笔记和 Markdown；页面视图可拖到另一侧栏。

安装版设置保存在 `%APPDATA%\InkspaceVSCodium\UserData`，用户扩展在同级 `Extensions`，与原有 VSCodium 和旧便携版分开。现有笔记通过打开文件夹访问；卸载保留笔记、设置和用户扩展。升级前请保存工作并关闭安装版窗口。

**必须使用专用原生宿主。只在普通 VSCodium 中安装 VSIX 不提供高精度书写，扩展会阻止浏览器笔输入。** 等待触控笔时，底部显示原生输入状态；收到真实高精度样本后才显示高精度已连接。设备只提供像素坐标时不继续书写。

## 输入路线

专用宿主在 Electron 主进程挂接自己的 Windows HWND，读取 Windows Pointer 历史采样、原始压力及经设备/显示器标定的 HIMETRIC 小数坐标。坐标经 Webview 嵌套位置与缩放转换，保留全部采样；压力轮廓及抗锯齿由已有 Xournal++ / Cairo 原生引擎生成。浏览器笔事件不会重复产生墨迹，鼠标不书写。

原生模块与画布通过本机回环连接通信，使用每次启动随机认证密钥。宿主自动更新已关闭，升级 VSCodium 时需要重新构建原生宿主。真实触控笔延迟、压感及防误触仍需设备实测，自动测试不能证明与 OneNote 体验相同。

## 构建与验证

仓库根目录执行 `npm run build:vscodium-native`；需要本机已安装 VSCodium 及已构建的 Windows 原生模块。在 `vscode` 目录打包 VSIX，安装到专用宿主的 `data/extensions`。`npm run test:vscode` 默认使用专用宿主和独立测试配置。

制作安装程序执行 `npm run dist:vscodium`；需要已有专用宿主和 NSIS 3 编译器（可通过 `INKSPACE_MAKENSIS` 指定）。打包只收集运行时和当前扩展，不收集便携版用户目录。当前扩展作为内置扩展随安装程序分发，原始第三方许可随包保留。卸载按安装文件清单逐项删除，不递归清空用户选择的安装目录。

测试覆盖小数坐标、侧栏及宿主缩放、全部 300 个密集样本保留、Cairo 像素一致性、精度丢失时结束笔迹、浏览器笔/鼠标不书写，以及文件保存、外部更新、撤销、图片、PDF 和公式。合成样本明确标记，不计为真实高精度输入。

GPL-2.0-or-later；源码：https://github.com/nollasalt/inkspace 。来源见 `native/UPSTREAM.md`。原独立桌面版保留。

0.2.1 将书写和静态画布改为异步二进制像素传输；Cairo 在独立进程中计算，主进程专注 Windows 输入。连续更新只允许一份活动绘制请求，积累的样本全部保留；不再每隔 1.5 秒重新遍历所有 Webview。

0.2.2 抬笔只结束接触状态，最终墨迹异步合成到局部区域；不重建文本/PDF。自动同步在停笔 700ms 后合并执行，Ctrl+S 立即同步。

原生宿主现按顺序批量派发输入，每批最多 128 个事件，保留所有落笔、移动、抬笔及原始采样，避免逐个事件等待一次画布脚本执行。`/status` 返回派发批数、事件数、最大批大小和执行等待时间，便于诊断传输积压。

一次相同机器、独立配置的前后验证中，60 次连续打点的 120 个事件从逐条派发改为一批派发，输入测试请求完成时间从约 336ms 降至 55ms。测试保留全部点，并验证最终 Cairo 像素一致。该数字包含测试坐标查询及请求返回时间，不代表真实触控笔到屏幕延迟，也不能保证其他负载下的结果。


0.5.0 新笔记使用 `.ink` 二进制追加记录，通过 CustomEditorProvider 保存。笔迹坐标和压力使用 Float64；书写只传输并追加变化，避免整本 JSON 序列化和文本编辑。已完成笔迹保留到 Cairo 提交，不在下一次落笔时清除。旧 JSON 编辑器保留兼容，推荐转换后使用新格式，格式与恢复说明见 `docs/BINARY_FORMAT.md`。

## 合并自动保存（.ink）

自动保存失败后会逐步延长重试间隔（5–60 秒），同一轮失败只提示一次。原文件保存失败不再阻止 VS Code 生成恢复备份。文件冲突时，可运行 **墨境：保存当前画布的恢复副本**，将当前画布另存为新的 `.ink` 文件。

遇到卡顿时，复现后运行 **墨境：查看性能与保存诊断**。报告在 JSON 标签页中显示输入处理、抬笔、原生栅格往返、撤销和磁盘提交耗时；最近统计仅保留 128 个样本，不包含正文、笔迹坐标、文件路径或连接令牌。异常退出可恢复完整文件记录和已有恢复备份，尚未进入两者的改动无法保证保留。

修改先进入插件宿主内存，停止修改 2 秒后合并写入；持续编辑时最多等待 10 秒。Ctrl+S 与切换笔记会立即保存，关闭时遵循 VS Code 的保存/放弃及恢复机制。突发断电可能丢失尚未落盘的最近修改。旧 JSON 笔记继续使用原来的保存方式。

在 VS Code 设置中搜索 `Inkspace Auto Save`：`inkspace.autoSaveDelay` 控制空闲延迟，`inkspace.autoSaveMaxDelay` 控制连续编辑的最大间隔，单位均为毫秒；重新打开笔记后生效。VS Code 自身自动保存也可以提前提交。

侧栏显示当前工具属性，或由顶栏图形、PDF、纸张入口打开的对应资源。所有资源入口都采用点击展开、再次点击收起的规则；资源入口的下划线表示面板展开，工具按钮的实色高亮表示操作模式，二者分开显示。纸张面板提供背景设置、SVG 导出与触控笔校准。切换工具返回对应属性；查看资源时点击当前工具也可回到属性。收起侧栏后切换工具不会自动展开。

侧栏中的笔粗、笔绘图形类型、图形线宽、纸张方向、背景、字号与背景间距直接显示为按钮组选项，当前值高亮；可直接点击切换，无需展开下拉菜单。

文本框支持两种视图，鼠标悬停时显示统一的窄灰控制栏：左端图标切换全部显示和小窗，中间拖动移动文本框，右端调整宽度。小窗只常驻细灰边框，悬停时显示底部中央的高度握柄，右下角保留整体缩放。文本控件随画布和文本一起缩放；图片控件保留固定屏幕大小。拖高松开后自动保存并作为一步撤销，Esc 可取消当前拖动，握柄聚焦后上下方向键微调高度。切回小窗保留上次高度，滚轮滚动内容，Ctrl+滚轮缩放画布，双击编辑完整 Markdown。视图按文本框自动保存，滚动位置仅保留在当前打开会话内。

手动新建空的 `.ink` 文件后直接打开即可：插件自动初始化一页白底横线画布，以文件名命名并保存，无需通过「创建笔记」按钮。

鼠标悬停文本框或图片时，外侧显示上、右、下、左四个连接箭头。点击一个箭头，再点击目标文本框、图片或图形完成连接；点击空白创建自由端点，Esc 取消。也可从图形连接点拖到文本或图片，连接会随对象移动和缩放更新。


0.10.0：顶栏图形打开右侧库，模板默认插入可见画面中心，可切换拖动绘制。点选块使用悬浮条；视觉介质等比缩放，文本右侧改变宽度、小窗底边改变高度，字号独立设置。双击 Markdown 编辑对应源码片段，完整源码可切换，Ctrl+Enter 完成、Esc 取消。文本编辑期间 Ctrl+Z 和撤销命令只操作本地文字，完成后一次进入笔记历史。属性栏左缘可调整宽度。

当前新笔记默认连续画布，A4 为可选布局。文本为基本源码编辑、HTML 仅静态展示、图形聚焦笔记常用能力。完整范围见 [产品范围](../docs/PRODUCT-SCOPE.md)。
