# Changelog

## 0.3.11

- P / E / H / T / V / S 工具快捷键支持再次按下返回上一个工具；按住按键不会反复切换。
- 工具栏点击继续直接选择工具，同时更新快捷键返回的目标。

## 0.3.10

- 聚焦画布时由一个键盘处理器接管撤销重做，阻止快捷键重复分发和按键自动重复，确保每次按键只操作一步。
- A4 纸张固定为纯白色，保留空区域的浅灰背景和已使用纸张的底纹。

## 0.3.9

- 触控笔框选仅更新选框；拖动缩放使用已有图层预览，抬笔后一次性提交笔迹变换。
- Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z 统一走笔记撤销重做，修复文件同步冲突。
- 同步 VS Code 菜单的撤销重做，统一 Windows 换行符，防止无内容变化的写入清空重做记录。

## 0.3.8

- A4 拼接中未使用的区域改为纯灰色，不显示横线、网格或点阵。
- 纸张颜色与底纹仅绘制于内容占用的 A4 页面内。

## 0.3.7

- A4 纸张无间隔拼接，边界改为淡虚线。
- 仅显示笔迹、图形、文本或图片占用的纸张，越界自动拓展，删除后收回空纸张。
- 缓存已完成笔迹的纸张占用，实时输入仅更新新线段，不触发笔迹重绘。

## 0.3.6

- 笔记内容停止编辑约 0.7 秒后自动保存，视图和页面配置也随之保存。
- 页面设置新增 A4 竖向、横向无限拼接显示，保留无限画布选项。

## 0.3.5

- 框选后可拖动右下角手柄等比例缩放笔迹、图形、文本框和图片，支持撤销重做。
- 默认使用白色空白背景，旧默认背景颜色转为白色。

## 0.3.4

- 修复 Alt+Tab 返回后必须点击鼠标才能书写，改用 VS Code 窗口与活动编辑器状态判断输入焦点。

## 0.3.3

- 隐藏 Cairo 工作进程的控制台窗口，启动和故障恢复时均在后台运行。

## 0.3.2

- 修复 Cairo 子进程退出后 IPC 错误导致引擎崩溃，自动恢复绘制进程。
- 启动时确认采样和绘制均已就绪，记录子进程日志，并清理继承的 IDE 启动变量。

## 0.3.1

- 移动、缩放时即时显示完整笔迹轮廓，可见区域的 Cairo 位图就绪后统一替换，避免逐笔加载。
- 复用常见笔迹完整位图，限制栅格并发，跳过过时视图请求。
- 页面背景、颜色、间距和字号自动保存。
- 文件栏右键直接在当前目录创建笔记，重名自动编号。
- 提供含原生运行时的 Windows x64 VSIX 和对应源码分发包。

## 0.3.0

- 独立 Raw Input + Cairo 引擎接入普通 VS Code 插件，不修改 IDE 主程序。
- 打开笔记自动启动或复用引擎。
- 校准结果按稳定设备标识和显示配置持久化，重开画布自动恢复。

## 0.2.3 及更早版本

VSCodium 原生宿主路线，保留在仓库中用于参考与回归。
