# Changelog

## 0.5.37

- Ctrl+F 搜索当前笔记的文本框 Markdown 原文与页名，显示跨页结果；Enter / Shift+Enter 跳转，Esc 关闭并回到画布。点击结果后直接恢复画布焦点，不改变当前绘图工具。
- 搜索定位保持目标页的缩放，滚动小窗自动显示匹配行；支持中文、大小写不敏感的字面量匹配，结果上限 300 条，不在书写过程中扫描整本笔记。
- 状态栏提供搜索、后退、前进入口，Alt+左右方向键恢复之前的页面、缩放、位置与小窗滚动，浏览历史不占用绘图撤销。
- 新页面插入当前页之后，默认名称避免重复；页面侧栏右键可上移、下移，边界处隐藏无效操作，排序支持撤销重做并自动保存。
- 搜索或切页前提交正在编辑的文本和图形标签，避免导航丢失刚输入的内容；对话框中保留原有键盘操作。
- 增加真实鼠标、键盘导航以及正式 VS Code 搜索入口、排序撤销、保存重开回归。

## 0.5.36

- 自动保存失败后按 5 秒起步、最多 60 秒间隔重试，同一轮失败仅提示一次；关闭文档后停止重试。
- 修复本次写入留下的半条记录导致再次保存被误判为外部修改的问题；重试前验证尾部内容，保留真实外部修改。
- VS Code 恢复备份独立于原文件保存，保存当前内存中的最新内容；增加“保存当前画布的恢复副本”命令，在文件冲突时也可另存当前画布。
- 压缩整理固定保存快照，避免整理期间的新笔迹被重复追加。
- 增加“查看性能与保存诊断”命令，提供输入处理、抬笔、原生栅格绘制、撤销、保存耗时及引擎状态；仅保留最近 128 个耗时样本，不包含笔记正文、坐标或文件路径。
- 增加写入失败、同步失败、并发整理、五种进程强制终止以及 100 次快速打点、焦点返回和像素显示回归。

## 0.5.35

- 双击文本框时，从双击文字对应的 Markdown 原文位置开始编辑，保留原有文本编辑和撤销操作。
- 光标定位支持缩放、标题、粗体、链接、代码块、转义字符、中文和换行；小窗滚动后进入编辑会显示光标所在行。
- 增加渲染位置到原文位置的回归，以及真实鼠标双击、插入文字和 Ctrl+Z 验证。

## 0.5.34

- 手绘图形模式在文本框和小窗中正确接管绘制事件，禁止浏览器拖选渲染文字，避免图形绘制被文字选择打断。
- 切到手绘图形时结束文本编辑；编辑器内仍可选择文字，原有移动、调宽、缩放控件保留。
- 保留现有四向连接箭头，未采用按像素间隔排列的连接点。
- 真实鼠标和原生笔回归覆盖普通文本、小窗文本、编辑器文字选择和四向连线。

## 0.5.33

- 使用现有 mxGraph 箭头渲染和编辑，支持文本、图片与图形之间连接，连接端点随移动、缩放、改宽和改高实时更新，删除对象时隐藏相关连线，撤销后恢复。
- 连线一步撤销，保存重开恢复附着关系；修复二进制增量消息经 Webview 传输时可选字段删除丢失的问题，避免撤销新增图形后保存残留。
- 真实鼠标和 VS Code 回归覆盖四向点击、笔悬停、移动缩放、图形双向连接、删除撤销与保存重开。
