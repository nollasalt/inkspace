# Changelog

## 0.4.4

- 移动工具优先接管触控笔拖动，支持从文本正文、链接、标题栏、缩放手柄与图片上移动画布；空格与鼠标中键/右键移动同样优先于文本操作。
- 画布工具栏新增图形/PDF 侧栏收起与展开按钮，收起后扩大画布；记住状态，重绘、自动保存、撤销同步和 Webview 恢复均保留偏好。
- 新增原生输入集成回归，覆盖五种文本框表面、三种缩放倍率以及侧栏布局/状态保持。

## 0.4.3

- 图形鼠标事件整体按显示帧合并，取消预览的额外帧等待，释放时处理最后位置；拖动不重绘完整笔迹或全部图形。
- 连线预览复用 mxGraph 原生路由、箭头和标签定位，移动中与提交后保持一致。
- 修复角点连接与缩放冲突，四角缩放固定对角并实时显示，吸附精确 A4 页边；清理原地蓝色选择框。
- 启用原生图形对齐辅助线，支持 Shift 多选、框选图形、中键/右键平移且保留选择。
- 绘图模式下滚轮滚动、Shift+滚轮横向滚动，Ctrl/Alt+滚轮缩放；其他工具保留原滚轮缩放。
- VS Code 自动化覆盖四角和三种缩放倍率、400 个事件合并，以及 202 个图形/21 条连接线的连续 60 帧拖动。

## 0.4.2

- 左侧栏提供 PDF 文件列表与删除按钮，也可从“文件 → 管理 / 删除 PDF”定位；支持撤销/重做，保留独立笔迹与文字批注。
- 图形拖动使用按帧合并的 DOM 位移预览，避免逐采样重建图形、文字和笔迹；连线预览随端点更新，释放时提交一次。
- 移除中央悬停的绿色连接高亮，清理拖动及窗口失焦后的预览与连接点，消除原地边框残留。
- 拖动图形边缘吸附 A4 页边和角点，保留小数坐标；Alt 临时关闭吸附，无需改变 A4 尺寸。

## 0.4.1

- 修正图形中央拖动、连接点启动连线、连线遮挡图形和空白点击误选；连接后保留原选择。
- 图形库和样式移动到左侧栏，支持点击插入、拖入画布、上下层级及方向键微调。
- 撤销快捷键在 Webview 本地立即执行，保存延后；图形撤销复用 mxGraph 编辑记录，原生笔迹仅重绘变化区域。
- 页面固定采用 A4 自动拼接，移除无限画布切换；旧文件继续兼容。
- PDF 导入对齐视口中心所在的 A4 页面，等比适配、连续分页，文字层和批注导出同步缩放。

## 0.4.0

- 集成 draw.io 底层 mxGraph 图形编辑引擎，与笔迹共用无限画布。
- 鼠标点击选择、拖动移动、八个手柄缩放；双击编辑文字，支持 Markdown 和离线 LaTeX 公式。
- 八个附着点、正交连接箭头、连线随图形移动；支持图形复制粘贴、撤销重做、自动保存。
- D 切换图形编辑模式，支持基础图形、边线和填充配置、压缩/未压缩 draw.io 首页面导入及导出。
- 保留原生触控笔/Cairo 路线，图形编辑仅接收鼠标事件。

## 0.3.12

- 支持 Ctrl+C / Ctrl+V 复制粘贴选中的笔迹、图形、文本和图片，保留压感、大小及相对布局。
- 支持跨页面、跨笔记粘贴，生成独立对象与新文本/图片 ID，整次粘贴可一步撤销。
- 保留文本编辑器的原生复制粘贴和外部图片粘贴。

## 0.3.11

- P / E / H / T / V / S 工具快捷键支持再次按下返回上一个工具；按住按键不会反复切换。
- 工具栏点击继续直接选择工具，同时更新快捷键返回的目标。

## 0.3.10

- 聚焦画布时由一个键盘处理器接管撤销重做，阻止快捷键重复分发和按键自动重复，确保每次按键只操作一步。
- A4 纸张固定为纯白色，保留空区域的浅灰背景和已使用纸张的底纹。

## 0.3.9

- 触控笔框选仅更新选框；拖动缩放使用已有图层预览，抬笔后一次性提交笔迹变换。
- Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z 统一走笔记撤销重做，修复文件同步冲突。
- 同步 VS Code 菜单的撤销重做，统一 Windows 换行符，防止无内容变化的写入清空重做记录。

## 0.3.8

- A4 拼接中未使用的区域改为纯灰色，不显示横线、网格或点阵。
- 纸张颜色与底纹仅绘制于内容占用的 A4 页面内。

## 0.3.7

- A4 纸张无间隔拼接，边界改为淡虚线。
- 仅显示笔迹、图形、文本或图片占用的纸张，越界自动拓展，删除后收回空纸张。
- 缓存已完成笔迹的纸张占用，实时输入仅更新新线段，不触发笔迹重绘。

## 0.3.6

- 笔记内容停止编辑约 0.7 秒后自动保存，视图和页面配置也随之保存。
- 页面设置新增 A4 竖向、横向无限拼接显示，保留无限画布选项。

## 0.3.5

- 框选后可拖动右下角手柄等比例缩放笔迹、图形、文本框和图片，支持撤销重做。
- 默认使用白色空白背景，旧默认背景颜色转为白色。

## 0.3.4

- 修复 Alt+Tab 返回后必须点击鼠标才能书写，改用 VS Code 窗口与活动编辑器状态判断输入焦点。

## 0.3.3

- 隐藏 Cairo 工作进程的控制台窗口，启动和故障恢复时均在后台运行。

## 0.3.2

- 修复 Cairo 子进程退出后 IPC 错误导致引擎崩溃，自动恢复绘制进程。
- 启动时确认采样和绘制均已就绪，记录子进程日志，并清理继承的 IDE 启动变量。

## 0.3.1

- 移动、缩放时即时显示完整笔迹轮廓，可见区域的 Cairo 位图就绪后统一替换，避免逐笔加载。
- 复用常见笔迹完整位图，限制栅格并发，跳过过时视图请求。
- 页面背景、颜色、间距和字号自动保存。
- 文件栏右键直接在当前目录创建笔记，重名自动编号。
- 提供含原生运行时的 Windows x64 VSIX 和对应源码分发包。

## 0.3.0

- 独立 Raw Input + Cairo 引擎接入普通 VS Code 插件，不修改 IDE 主程序。
- 打开笔记自动启动或复用引擎。
- 校准结果按稳定设备标识和显示配置持久化，重开画布自动恢复。

## 0.2.3 及更早版本

VSCodium 原生宿主路线，保留在仓库中用于参考与回归。
