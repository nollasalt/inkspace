# Changelog

## 0.5.10

- 文本框悬停提示只响应鼠标；浏览器及 Raw Input 笔悬空/书写均不触发控件。
- 文本框右下角新增整体等比例缩放把手，复用框选缩放预览与撤销流程，保持换行宽度及左上角文字位置。
- 顶部操作条缩短至最多 48 像素，保留移动及宽度调整。
- Chromium 原生鼠标输入与 VS Code 回归覆盖双击、缩放、笔悬停、保存及撤销。

## 0.5.9

- 修复浏览器鼠标捕获将文本双击重定向到画布，导致无法编辑或错误创建空文本框；文本操作由当前文本框捕获鼠标。
- 增加 Chromium 原生鼠标按下/抬起回归，验证书写、移动、选择三种工具下双击进入已有文本编辑，不产生额外文本框。

## 0.5.8

- 修复移动画布工具拦截鼠标拖动文本框和调整宽度，显式文本控件优先响应左键操作。
- 文字与上方操作条之间加入连续悬停区域，修复鼠标移向控件时操作条消失；编辑器仍可正常选择文字。
- 增加三种缩放比例下的控件命中、悬停连通及移动工具回归。

## 0.5.7

- 双击已有文本框直接编辑，修复先使用触控笔后鼠标双击无效。
- 文本框仅由实际文字区域接收鼠标，修复相邻文本框误选；编辑器保留原有换行宽度。
- 悬停显示灰色实线边框，上方灰色操作条提供拖动和右端宽度调整。

## 0.5.6

- 文本悬停时显示淡虚线边框，按实际文字范围描边；移开后隐藏，透明底色保持。
- 移动把手与首行开头对齐，宽度调整把手与末行结尾对齐，支持 Markdown、公式和原位编辑；保留原有文字位置及排版。
- 宽度调整按拖动位移计算，修复把手位于短文字末尾时的宽度跳变。文字范围按内容缓存，平移和缩放复用世界坐标。
- 新增 75%、100%、200% 下的文字首尾对齐、移动把手和宽度调整回归。

## 0.5.5

- 文本框改为透明背景，取消可见边框、圆角、阴影和编辑外框；移动标题与缩放把手仅在悬停或选中时显示。
- 保留原文字位置、宽度和排版，避免与已有叠加笔迹错位；图片不受影响。
- 原位编辑回归增加透明底、透明边框、无阴影与无编辑外框检查。

## 0.5.4

- 鼠标双击画布直接创建文本框并聚焦框内输入，不再打开创建窗口；双击已有文本也原位编辑 Markdown 源文。
- 输入自动保存；点击框外、Ctrl+Enter 或 Escape 完成编辑并显示 Markdown/公式。未输入内容的新文本框离开时移除。
- 编辑控件保留世界坐标与字号，缩放和重绘不替换输入控件或光标；触控笔仍可在正在编辑的文本框上书写。
- 新增普通 VS Code 回归：双击创建、焦点、无弹窗、自动保存、公式、缩放光标、一步撤销及笔迹叠加。

## 0.5.3

- 空笔记显示一张初始 A4 纸；新增纸张按实际内容扩展，空文本框和其他页面的旧图形缓存不再占用额外纸张。纸张外保持灰色。
- 新笔记和缺省背景改用横线，已有笔记的自定义背景保留。
- 侧栏开关移至画布左侧边缘，收起后仍能直接展开。PDF、draw.io 导入导出及校准操作归入侧栏；顶部移除重复文件菜单，保留工具、撤销/重做和页面设置。
- 回归覆盖空文本框、空笔记的单张初始纸、默认横线、侧栏开关位置和资源入口。

## 0.5.2

- 橡皮擦按接触建立空间索引，只检测附近笔迹；合并原生采样并检测移动路径，快速扫过笔迹也能命中。
- 按显示帧合并擦除变化，只更新删除区域，避免每个采样重绘画布及重建文本/图形；抬笔、切换工具或失焦提交剩余变化，整次擦除保持一步撤销。
- 增加 VS Code 宿主侧 P/E/H/T/V/S/D 工具快捷键和命令。笔记可见、焦点位于侧栏时仍能切换，再次按键返回原工具；输入框和终端保留文字输入。
- 新增 1,000 条笔迹/400 个橡皮采样的性能与像素回归，覆盖快速越过、一步撤销、保存和笔记失去键盘焦点时的工具命令。

## 0.5.1

- 抬笔后清理实时书写层，完成笔迹只保留一份预览，修复最后一笔固定在屏幕位置的残影。
- 平移、缩放和缓存平移前，将待提交笔迹合入其原始视图；后台 Cairo 在平移期间完成时也按画布缓存视图提交，避免位置偏移。
- 取消触控笔浏览器默认长按行为，并屏蔽画布右键菜单，保留鼠标右键平移。
- 新增普通 VS Code 回归：抬笔图层清理、后台绘制期间平移、缓存边界平移、缩放像素和右键菜单。

## 0.5.0

- 新建笔记改为 `.ink` 二进制文件，使用 CustomEditorProvider；Float64 坐标/压力、压缩基线和带校验的追加增量，避免书写时整本 JSON 序列化、Webview 传输和文本替换。
- 完成笔迹增加独立保留层，下一笔开始时仍可见，直到 Cairo 提交；释放时局部提交，不重绘整幅场景。
- Raw Input 按批读取视口、焦点和显示信息，书写中的光标使用缓存坐标，减少高频布局读取。
- 自动保存直接提交变化，保留页设置、图形、PDF、图片、文本、撤销和恢复；支持不完整记录恢复、末尾损坏恢复、外部修改检测和空闲日志压缩。
- 保留旧 JSON 编辑器，提供备份、精确校验的转换脚本。集成测试覆盖 1,000 条背景笔迹上的连续书写、预览保持、自动保存、撤销、重开、公式与页切换；格式测试覆盖精度、校验、恢复和压缩。

## 0.4.4

- 移动工具优先接管触控笔拖动，支持从文本正文、链接、标题栏、缩放手柄与图片上移动画布；空格与鼠标中键/右键移动同样优先于文本操作。
- 画布工具栏新增图形/PDF 侧栏收起与展开按钮，收起后扩大画布；记住状态，重绘、自动保存、撤销同步和 Webview 恢复均保留偏好。
- 新增原生输入集成回归，覆盖五种文本框表面、三种缩放倍率以及侧栏布局/状态保持。

## 0.4.3

- 图形鼠标事件整体按显示帧合并，取消预览的额外帧等待，释放时处理最后位置；拖动不重绘完整笔迹或全部图形。
- 连线预览复用 mxGraph 原生路由、箭头和标签定位，移动中与提交后保持一致。
- 修复角点连接与缩放冲突，四角缩放固定对角并实时显示，吸附精确 A4 页边；清理原地蓝色选择框。
- 启用原生图形对齐辅助线，支持 Shift 多选、框选图形、中键/右键平移且保留选择。
- 绘图模式下滚轮滚动、Shift+滚轮横向滚动，Ctrl/Alt+滚轮缩放；其他工具保留原滚轮缩放。
- VS Code 自动化覆盖四角和三种缩放倍率、400 个事件合并，以及 202 个图形/21 条连接线的连续 60 帧拖动。

## 0.4.2

- 左侧栏提供 PDF 文件列表与删除按钮，也可从“文件 → 管理 / 删除 PDF”定位；支持撤销/重做，保留独立笔迹与文字批注。
- 图形拖动使用按帧合并的 DOM 位移预览，避免逐采样重建图形、文字和笔迹；连线预览随端点更新，释放时提交一次。
- 移除中央悬停的绿色连接高亮，清理拖动及窗口失焦后的预览与连接点，消除原地边框残留。
- 拖动图形边缘吸附 A4 页边和角点，保留小数坐标；Alt 临时关闭吸附，无需改变 A4 尺寸。

## 0.4.1

- 修正图形中央拖动、连接点启动连线、连线遮挡图形和空白点击误选；连接后保留原选择。
- 图形库和样式移动到左侧栏，支持点击插入、拖入画布、上下层级及方向键微调。
- 撤销快捷键在 Webview 本地立即执行，保存延后；图形撤销复用 mxGraph 编辑记录，原生笔迹仅重绘变化区域。
- 页面固定采用 A4 自动拼接，移除无限画布切换；旧文件继续兼容。
- PDF 导入对齐视口中心所在的 A4 页面，等比适配、连续分页，文字层和批注导出同步缩放。

## 0.4.0

- 集成 draw.io 底层 mxGraph 图形编辑引擎，与笔迹共用无限画布。
- 鼠标点击选择、拖动移动、八个手柄缩放；双击编辑文字，支持 Markdown 和离线 LaTeX 公式。
- 八个附着点、正交连接箭头、连线随图形移动；支持图形复制粘贴、撤销重做、自动保存。
- D 切换图形编辑模式，支持基础图形、边线和填充配置、压缩/未压缩 draw.io 首页面导入及导出。
- 保留原生触控笔/Cairo 路线，图形编辑仅接收鼠标事件。

## 0.3.12

- 支持 Ctrl+C / Ctrl+V 复制粘贴选中的笔迹、图形、文本和图片，保留压感、大小及相对布局。
- 支持跨页面、跨笔记粘贴，生成独立对象与新文本/图片 ID，整次粘贴可一步撤销。
- 保留文本编辑器的原生复制粘贴和外部图片粘贴。

## 0.3.11

- 工具栏点击继续直接选择工具，同时更新快捷键返回的目标。

## 0.3.10

- A4 纸张固定为纯白色，保留空区域的浅灰背景和已使用纸张的底纹。

## 0.3.9

- Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z 统一走笔记撤销重做，修复文件同步冲突。
- 同步 VS Code 菜单的撤销重做，统一 Windows 换行符，防止无内容变化的写入清空重做记录。

## 0.3.8

- A4 拼接中未使用的区域改为纯灰色，不显示横线、网格或点阵。
- 纸张颜色与底纹仅绘制于内容占用的 A4 页面内。

## 0.3.7

- 仅显示笔迹、图形、文本或图片占用的纸张，越界自动拓展，删除后收回空纸张。
- 缓存已完成笔迹的纸张占用，实时输入仅更新新线段，不触发笔迹重绘。

- 默认使用白色空白背景，旧默认背景颜色转为白色。

## 0.3.4

## 0.3.3

## 0.3.1

- 复用常见笔迹完整位图，限制栅格并发，跳过过时视图请求。
- 页面背景、颜色、间距和字号自动保存。
