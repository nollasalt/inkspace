# Inkspace 工作台与通用介质控件

状态：0.9.0 已接入普通 VS Code 插件。工作台、公共悬浮条、右侧图形库和 Markdown 片段编辑已实现。

## 分工与布局

VS Code 提供文件资源管理器、编辑器标签、文件保存、终端及设置。Inkspace 的笔记编辑区域只保留一行紧凑顶栏、画布、右侧上下文栏和底部状态栏，不重复制作宿主菜单或文件栏。左侧文件区仍属于 VS Code。

| 区域 | 职责 | 内容 |
| --- | --- | --- |
| 顶栏左侧 | 选择当前输入工具或图形创建 | 编排、画笔、橡皮、图形；高频工具直接展示 |
| 顶栏中部 | 创建与全局设置 | 一个插入入口、页面设置 |
| 顶栏右侧 | 布局 | 属性栏显示/隐藏；不占一条竖栏 |
| 右侧上下文栏 | 调整工具或对象属性与访问图形库 | 当前工具、单块、多选、页面设置、临时图形库；同一位置显示一个上下文 |
| 选区悬浮条 | 直接操作当前对象 | 编辑/查看、小窗切换、更多；多选为组合和更多 |
| 底栏 | 位置与状态 | 画布切换、缩放/适合视图、保存状态与引擎状态 |

页面设置中的“纸张”指画布中的 A4 拼接单元。“画布切换”指笔记内独立画布，保留原功能，不把二者混称为页面。缩放入口放在底栏，不重复展示顶栏缩放参数。

## 顶栏与插入

编排是鼠标默认工具，鼠标可点选、拖动、框选和双击编辑。鼠标明确切换画笔/橡皮/图形后直接使用该工具，不再有“启用鼠标绘图”开关。中键始终临时平移。H 保留给笔平移，第二次按 H 返回原工具；不新增占据顶栏空间的移动按钮。

插入菜单承载文本、图片和 PDF。文本默认 Markdown；HTML 是文本块的格式选项，不另造独立 HTML 框。PDF 导入后每页作为独立块。“图形”与画笔、橡皮并列，是图形库及标准形状绘制的唯一入口；插入菜单不再重复图形库。图形库在右侧栏显示，暂时替换属性面板，不弹出中央窗口。顶部只负责打开图形库，模板和创建方式位于侧栏。

图形创建提供两种互补路径：默认“居中插入”，点击模板后立即创建并选中，图形库保持打开，便于连续插入；“拖动绘制”，选中模板后退出图形库，在画布拖动确定位置和尺寸。两种路径生成完全相同的图形块，拥有相同标签、连线、复制、移动和缩放能力。点击绘制使用默认尺寸；拖动绘制使用实际拖动范围。一次绘制完成后回到编排；连续绘制需显式选择。图形库通过返回属性、Esc 或再次点击顶部图形入口退出。取消绘制时不留下空块或历史项。

取消独立的“手绘图形”工具。画笔负责自由墨迹、书写、草图和标注；图形负责标准几何及流程结构。后续若做笔迹规整，应作为画笔的可选完成动作，把同一笔迹转换成图形块，不再增加第三套形状模型和输入模式。规整必须可撤销，不默认改变普通书写。

视图中心指当前实际可见画布区域，排除属性栏，不是整份无限文档的中心，也不是固定世界坐标。创建时先稳定布局，再使用视口逆变换：`worldCenter = screenToWorld(viewportCenter)`，最后减去块尺寸的一半得到左上角。平移、缩放、侧栏宽度与宿主分栏变化均须纳入计算。默认文本/图片/PDF 导入同样遵守可视中心策略；PDF 多页以首项居中并排列，空白处双击新建文本则遵守用户点击位置。

新增介质由注册表向插入命令贡献能力；将来 XLSX 可贡献导入入口和工作表属性，无需重新设计顶栏。未实现的介质不出现在可点击产品菜单中。

## 上下文栏的确定规则

普通上下文由工具和选择产生：编排无选区时显示画布概览；有单选时显示该介质；多选时显示公共编排属性；画笔/橡皮/图形绘制时显示工具参数。页面设置和图形库进入临时侧栏上下文，提供“返回属性”和关闭按钮。图形库期间仍可在画布编排，选区变化不会强行切回属性；明确返回后显示当前选区或工具属性。打开资源面板本身不更换工具或创建块。

侧栏是否可见独立于上下文。用户收起后，点选块、编辑块、切换工具保持收起。主动请求图形库或页面设置时展开侧栏；返回属性或 Esc 退出后恢复进入前的可见性。点击关闭/隐藏则明确收起，不能因先恢复旧状态再取反而重新展开。侧栏宽度、显示状态和各节展开状态属于工作区 UI 设置，不加入笔记撤销历史。

属性按任务组织，不按内部类型字段排列：

- 文本：格式（Markdown / HTML）、显示（全显 / 小窗）、排版宽度、窗口高度、整体比例。
- 图片 / PDF：尺寸、比例、原稿信息及对应操作。PDF 原稿文字选择放在内容会话中。
- 图形：形状、填充、边线、标签；选项平铺，长列表用资源库承载。
- 多选 / 组合：数量、整体尺寸、整体比例、对齐、组合 / 取消组合；不显示某一成员的私有属性。
- 连接线：端点、线型和箭头，更新整条路由，避免穿过对象内部。
- 工具：笔宽、颜色等高频项平铺。高级项使用折叠节，不堆进顶栏下拉框。
- 页面：白色纸张、横线/空白/网格、A4 拼接边界和占用策略。空的新画布有一张初始纸张，之后按内容占用拓展，拼接无间隔。

进入文本编辑时保留当前块上下文；侧栏输入字段有自己的键盘所有权，Ctrl+Z 不应撤销整个笔记。更换工具是明确命令：先提交或取消当前编辑事务，再切换工具，不留下半开的内容会话。

## 公共框与悬浮条

单选只显示一条悬浮操作条。鼠标悬停提供灰色实线与四向连线入口；选中提供细蓝框、对应尺寸柄和悬浮条。小窗空闲保留细灰框，普通块空闲隐藏框。笔悬停与书写不显示编排控件。

悬浮条为 26 屏幕像素高，不随块或画布缩放。编辑/查看取决于介质能力；全显与小窗使用同一个按钮、同一个位置；更多与右键菜单共享命令表。属性栏可提供同一状态的精确数值，不能另存一份开关状态。

移动、整体缩放、排版宽度和窗口高度是四种独立动作。右下整体缩放保持换行；右侧排版柄改变换行；底部窗口柄仅改变裁剪高度。屏幕控件与正文的世界几何完全分离，悬浮条和透明桥接区不影响框选、连接端点或纸张拓展。多选只显示公共框与公共操作条。

双击 Markdown 文字优先就地编辑命中的段落/列表项/代码片段，从点击位置定位光标；段落以上以下的渲染保持静止。提供“完整源码”切换，负责跨段落结构修改、复杂公式和 HTML。悬浮条编辑按钮或 Enter 是不依赖双击的明确入口，使用上次编辑位置或源码起始处。HTML 默认完整源码；图形默认标签。图像/PDF 默认查看。

片段编辑只修改对应源码范围，保留外部 Markdown 标记及未编辑段落，不把整块序列化为简化纯文本。布局、块尺寸和连接几何在编辑会话中冻结；临时编辑区域可以扩大，光标及文本开头尽量留在原屏幕位置。Ctrl+Enter/完成提交，Esc 取消；点击画布另一处先提交，再执行新命令。HTML 链接、PDF 选字及未来表格交互只能在明确的内容会话中获得输入权，不能拦截编排或笔书写。

生产实现要求渲染适配器提供 AST/source-map 支持的 `sourceRangeAtPoint`，返回准确源码范围、源偏移和屏幕文本锚点。公式、图片、复杂 HTML 无法精确定位时进入对应源码片段或完整源码，不凭可见字符长度猜源偏移。预览仅演示标题、普通段落、列表和代码行的直接映射，不冒充完整 Markdown 富文本编辑器。

## 架构契约

已有 InteractionMachine 继续管理手势所有权；工作台只增加上下文和命令映射，不引入另一套互相竞争的指针状态机。

```ts
type WorkbenchContext =
  | { kind: 'tool'; tool: ToolId }
  | { kind: 'selection'; ids: readonly BlockId[] }
  | { kind: 'canvas'; canvasId: CanvasId };

interface WorkbenchUiState {
  sidebar: { visible: boolean; width: number };
  resourceSession: null | {
    kind: 'page-settings' | 'shapes';
    previousVisible: boolean;
    placement?: 'center' | 'draw';
  };
}
```

`WorkbenchContext` 从活动工具、稳定 ID 选区和内容会话推导，不单独持久化一份“当前选中块”。临时上下文退出后重新推导，避免恢复陈旧选区。命令注册表提供 `id / label / icon / when / enabled / execute`，顶栏、插入、悬浮条、侧栏、右键和快捷键引用同一命令。

建议模块：`workbench/context.ts`（上下文推导）、`commands.ts`（共享命令）、`shell.ts`（布局）、`properties.ts`（能力属性贡献）、`resources.ts`（临时资源会话）。`MediaAdapter` 贡献属性定义与内容会话，不直接操控顶栏 DOM 或安装全局指针监听。

属性更改通过文档事务写入。拖动期间只预览，释放提交一次历史；属性数字输入在确认/失焦时提交，颜色连续调整在一次会话结束时提交。UI 布局偏好不触发笔记写盘。自动保存保留现有去抖与脏状态策略，不因每次 UI 上下文切换保存。

移动、缩放、切换上下文只更新变换或控件投影，不重建正文、PDF 缓存、mxGraph 模型或笔迹。右栏只挂载当前上下文面板，悬浮控件层最多一个选区条和一个悬停框。

## 窄窗口与可达性

侧栏默认右置约 224px，可调整宽度。窄编辑区使用临时覆盖面板，关闭后还给画布；不会为了适应窗口重新摆放真实块。顶栏允许紧凑折叠低频命令，工具名称可隐藏但保留可访问标签与快捷键。悬浮条贴近视口并在上方空间不足时翻到下方，不能超出可见范围。设计预览窄屏使用上下堆叠，便于在对话中完整检查界面。

## 验收与实施顺序

1. 建立共享命令和上下文推导，顶栏与现有侧栏同时迁移，删除重复图形/文件入口和独立手绘形状工具。
2. 接入公共 MediaFrame 悬浮控件，让文本、图片、PDF 和图形共用边界与手势，旧控件在迁移后删除。
3. 接入侧栏能力面板、临时资源会话及内容编辑会话；验证未来介质可只贡献能力而不改外壳。

验收：图形库唯一入口；侧栏收起偏好稳定；工具与选区属性一致；编辑不跳回画笔属性；鼠标绘图常可用；H 和中键平移可用；右键与更多动作一致；窄块控件不溢出；块缩放与视图缩放都不改变控件大小；移动/缩放不重建内容；每个完成动作一个历史项。画布切换和纸张设置须使用不同名称。

交互预览验证工作台布局、真实鼠标双击、片段定位及原生文字撤销、中心创建、几何拖绘、框选与控件切换，不连接真实文件、Ink Engine、完整 Markdown 渲染或避障路由，不代表插件已经更新。

## 完整操作规则

| 场景 | 单击 / 按下 | 拖动 | 双击 / 确认 | 退出 |
| --- | --- | --- | --- | --- |
| 编排中的块 | 选中；Shift 添加成员 | 超过阈值后移动选区 | 文本编辑、图形标签编辑或媒体查看 | Esc 取消当前手势 |
| 编排中的空白 | 清空选区 | 框选真实可见范围 | 在点击位置创建并编辑文本 | Esc 取消框选 |
| 图形库（侧栏） | 选模板与创建方式，居中插入后保持打开 | 选择拖动绘制后在画布操作 | 默认在可见画布中心创建 | 返回属性 / Esc / 顶部入口切换，恢复之前侧栏可见性 |
| 图形绘制 | 使用默认大小放置 | 按矩形范围创建标准形状 | 完成后选中并回编排 | Esc 取消；连续创建可单独退出 |
| 画笔 | 墨迹起笔，穿透内容 | 连续书写 | 抬笔完成一次墨迹事务 | 取消会话丢弃未完成笔迹 |
| 橡皮 | 擦除命中的笔迹 | 按移动范围持续擦除 | 抬笔完成一次擦除事务 | 取消恢复该会话擦除内容 |
| 内容编辑 | 本地光标或内容动作 | 选择文字/内部滚动 | 完成提交本地编辑 | Esc 取消并返回编排 |
| 任意内容上的中键 | 临时获得平移权 | 平移画布 | 松开回原会话 | 不变更当前工具 |

按下阶段只产生待定手势，不能立即移动块或捕获鼠标。移动超过阈值才升级为拖动并捕获；没有拖动的单击和第二次点击保留原内容命中，因此浏览器双击或显式双击识别仍能工作。第二次点击不能被第一次的悬浮控件重建改变目标。释放、取消、失焦、切换画布均结束所有权，旧适配器不得继续接收事件。

公共悬浮条与上/下连线入口使用不同垂直带，不能互相覆盖。控件投影时避开目标正文；其他块的正文优先于跨到它上方的连线入口。触控笔悬停不触发鼠标的 CSS 悬停会话，书写/擦除时关闭所有编排命中。透明桥接区仅延续悬停，永远不获得点击所有权。

## 选择、历史与文件

点选、Shift 多选、框选统一使用稳定 ID 选区。组合为显式文档对象，成员仍保留介质身份；组合外框是可见成员范围并集。拖动/缩放只显示一套控件。复制时生成新 ID，重映射组合与组内连接；组外连接需有明确保留/脱离策略，不能引用被删除的旧成员。

正文拖动移动块，角柄整体缩放，侧柄调整排版宽度，底柄调整窗口高度；轮滚只改变视图比例或滚动已进入的小窗内容。Ctrl+C/V、Delete、组合及层级操作由同一命令表执行。内容编辑期间这些按键由编辑器优先处理；退出后才用于画布。右键与更多菜单项目相同，选空白则显示粘贴与插入，不用旧选区冒充右键目标。

一笔、一次擦除手势、一次移动/缩放、一次导入/组合或一次编辑提交各形成一个历史项。视图移动、缩放、侧栏布局、悬停、菜单开关不进入文档历史。取消动作回到起始快照，不提交空事务。文件自动保存仍按脏状态与静默间隔合并，编辑会话草稿由恢复机制保护，保存状态使用真实宿主数据；预览只显示“设计预览”。

## 后续介质的接入约束

普通文本、HTML、图像、PDF 每页、图形和笔迹复用公共框；XLSX 后续贡献工作表及单元格内容会话。内容引擎不拥有块移动、框选、缩放或全局快捷键。导入失败保留原文件和当前文档，不生成半初始化块；加载中保留稳定框和占用范围。原稿资产、源文本与预览缓存分离，块移动/缩放不重新解析或重建资源。复杂介质以同一内容会话契约接入，就地片段无法可靠编辑时显式使用完整源码，而不是静默损坏文档。

当前先落地交互所有权、统一几何、命令与可测试会话，再接入媒体能力。扩展能力必须提供取消、撤销、坐标映射、焦点归还和资源释放契约，不能只新增一个按钮及若干事件监听。

## DESIGN 对照与 0.9.0 实现

界面按已确认的工作台预览重新构造，不保留旧的左侧资源栏、顶栏参数行、绿色按钮和块顶部长条。顶栏 39px，右栏默认 224px，右栏统一标题行 39px，图形卡片 65px，底栏 29px；选区条 26px、编辑条 30px。选中态浅蓝底配深色字，纸张白色，连线入口为四边外侧灰色圆钮。右侧排版柄 6×22px、窗口高度柄 22×6px、整体缩放柄 10×10px，画布和块缩放均不改变这些屏幕尺寸。

图形库默认显示矩形、圆角矩形、椭圆、判断；线条和 draw.io 原稿操作放在“更多图形与原稿”。页面面板显示白纸、背景和拼接规则，字号、方向和间距放在“更多设置”。Ctrl+F 与 Alt+←/→ 保留搜索和浏览历史，底栏不重复摆放这些入口。

验证新增实际 Chromium 中的布局与颜色断言：资源栏位于画布右侧、上述尺寸符合 DESIGN、缩放位于底栏、选中按钮字体可读。完整示意图是交互设计参考；纸张占用与真实媒体内容由已有文档模型决定。

## 0.9.0 实现与验证

- `workbench.js` 管理界面和临时资源会话；上下文从当前工具、稳定 ID 选区及内容会话推导。属性栏宽度通过顶栏旁右栏左边缘调整，176–380px，工作区记忆。
- `workbench-commands.js` 是顶栏插入、悬浮条和右键的公共命令注册表。`media-frame.js` 只投影一个屏幕控件层，不添加竞争的画布指针监听。
- `canvas-interaction.js` 保留唯一手势入口；正文按下不立即捕获鼠标，超过阈值才拖动。图形绘制只在释放时调用 mxGraph 创建，取消无历史项。
- Markdown 源码片段由 `InkContent.sourceRange` 复用 MarkdownIt AST 确定范围；源码偏移来自渲染锚点和字符映射。原源码范围外的 CRLF、Markdown 标记和段落不改写。复杂列表/HTML 不满足片段映射时进入完整源码。
- 文本草稿与文档事务分离；完成一次提交，Esc 取消。新空框不写入文件或历史。草稿按 400ms 静默间隔保存在 webview 恢复状态；同版本文件重新打开时恢复编辑，文件已变化时不自动覆盖。
- `vscode/adapter.js` 只负责宿主消息、保存、输入状态和恢复。原有测试诊断迁到 `vscode/diagnostics.js`，仅验证宿主加载。
- 图像/PDF 的“查看”打开已有图片或 PDF 预览缓存；PDF 原文选字仍通过 PDF 内容面板开启。PDF 导入保留对齐当前 A4 单元的既有逻辑。
- 图形属性继续复用 mxGraph 控件；文本和多选提供当前已实现的宽度、小窗、组合及公共几何。后续精确坐标/对齐面板和 XLSX 内容编辑还未接入，不显示虚构能力。

验证命令：`npm test`、`npm run test:workbench`、`npm run test:ownership`、`npm run test:interaction`、`npm run test:blocks`、`npm run test:text:caret`、`npm run test:text:mouse`、`npm run test:engine:workbench`。GUI 验证使用真实鼠标事件；普通 VS Code 验证使用真实独立引擎与合成精密笔数据，不替代实体触控笔实测。
