# 在其他电脑安装 Inkspace 0.10.0

适用于 Windows x64 桌面版 Microsoft VS Code。建议使用当前稳定版；本机测试版本为 1.140.0。暂不提供 macOS、Linux、Windows ARM64 或浏览器版运行时。

## 推荐：安装 VSIX

1. 将 `Inkspace-VSCode-0.10.0-Windows-x64-Bundle.zip` 复制到目标电脑并解压。
2. 安装或打开 Microsoft VS Code。
3. 按 Ctrl+Shift+P，运行 `Extensions: Install from VSIX…`（从 VSIX 安装），选择 `Inkspace-VSCode-0.10.0-win32-x64.vsix`。
4. 若提示，重新加载 VS Code 窗口。
5. 打开存放笔记的文件夹，在文件栏右键选择“墨境：新建笔记”；已有新格式笔记直接打开 `.ink`；旧 `.inkspace.json` 仍兼容。
6. 首次点击“校准触控笔”，依次点击三个圆圈。以后同一设备与显示配置自动恢复。换电脑需要在新电脑校准一次。

也可以在已提供 `code` 命令的终端中安装：

```powershell
code --install-extension .\Inkspace-VSCode-0.10.0-win32-x64.vsix --force
```

安装包内含 Raw Input 程序、Cairo 原生模块和引擎依赖。使用时不需要安装 Node.js、编译工具或本项目源码目录；引擎由 VS Code 自带的运行时启动。

## 文件和保存

- 新笔记为 `.ink`，可直接复制到其他电脑，其中保存笔迹、页面和嵌入资源。
- 校准保存在本机 VS Code 插件存储，不需要随笔记复制。
- `.ink` 笔记停止编辑约 2 秒后自动保存，持续编辑最多约 10 秒提交一次；可在设置中调整，Ctrl+S 立即保存。纸张采用 A4 竖向/横向拼接。
- 引擎连接信息和日志位于 `%USERPROFILE%\.inkspace-engine`。不要分享其中的 `connection.json`，它包含本机连接令牌。

每台设备能否提供后台坐标和压力取决于触控笔及驱动。引擎已连接但校准圆圈无响应时，可更新设备驱动并提供 `service.log` 及探针计数供排查；注册成功不等于实际收到笔数据。

## 分发包内容

- `Inkspace-VSCode-0.10.0-win32-x64.vsix`：直接安装的插件。
- `Inkspace-VSCode-0.10.0-Source.zip`：对应源码、原生依赖源码和构建脚本。
- `INSTALL.md`：本说明。
- `SHA256SUMS.txt`：文件校验和。

源码包供查阅和重建，不需要解压到 VS Code 插件目录。

A4 纸张无间隔，以淡虚线标记边界；仅显示内容占用的纸张，笔迹、图形、文本和图片越界时自动拓展，删除后收回空纸张。

## 操作与搜索

- Ctrl+F 搜索当前笔记的文本框 Markdown 原文，Enter / Shift+Enter 跳转，点击结果后可直接继续书写，Esc 关闭搜索。暂不提供手写笔迹、图片与 PDF 正文识别。
- Ctrl+F 打开搜索；Alt+← / Alt+→ 恢复缩放、画布位置和小窗滚动。
- 一个 `.ink` 可包含多个独立无限画布，A4 纸张随内容自动拼接。点击底栏当前画布名进入 VS Code 画布列表，可新建、切换、重命名、排序和删除独立画布；每个画布内的 A4 纸张仍随内容自动拼接。
- 按 V 编排对象；画笔、橡皮、图形绘制模式中鼠标与触控笔均使用所选工具，不需额外开关。
- 普通滚轮移动画布，Shift+滚轮横向移动，Ctrl+滚轮缩放；小窗文本优先滚动正文。按住鼠标中键可在任意工具下移动画布，松开恢复当前操作，不设单独移动工具。
- 图形库通过顶栏“图形”或 D / S 打开，模板位于右侧栏；默认居中插入，也可选择拖动绘制，两种路径生成同一种图形。插入菜单统一提供文本、图片、PDF。图形库/纸张设置退出时恢复侧栏原先可见性。PDF 原文选取仍在 PDF 内容面板中开启。

## 恢复与诊断

- 自动保存暂时失败时，按 5 秒起步、最多 60 秒间隔重试，同一轮失败只提示一次。
- 文件冲突或原文件无法保存时，保持画布打开，运行 **墨境：保存当前画布的恢复副本**，另存为一个新的 `.ink` 文件。
- VS Code 的恢复备份包含已传到插件的最新改动，即使原文件保存失败也可以生成。异常终止后，`.ink` 会恢复全部完整记录；尚未提交且未进入恢复备份的改动无法保证保留。
- 遇到卡顿时，在笔记中复现后立即运行 **墨境：查看性能与保存诊断**。报告以 JSON 标签页打开，可自行保存分享；不包含正文、笔迹坐标、文件路径或引擎令牌。
- 报告中的输入、抬笔和场景绘制是执行耗时，原生栅格耗时包含服务往返；它们不等于触控笔端到端显示延迟。最近耗时统计仅保留 128 个样本，不持续写诊断日志。

## 公共介质控件

鼠标点选后使用悬浮操作条编辑/查看、小窗切换与更多；拖动类型标签或正文可移动块，右下角统一缩放。文本右侧柄改变排版宽度，小窗底部柄改变高度。控件固定屏幕大小，属性栏左缘可调宽度。

双击 Markdown 从命中源码片段和字符位置编辑，周围段落保持原位；复杂内容回退到完整源码，操作条可切换完整源码。HTML 使用完整源码。Tab 缩进，Enter 延续列表，Ctrl+Z 只撤销本地文本，Ctrl+Enter/完成提交，Esc/取消放弃草稿。输入期间不改变文档历史，完成后一次提交并沿用自动保存。鼠标中键平移保留编辑会话。
