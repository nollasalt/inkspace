# Inkspace 二进制笔记

0.5.0 默认新建 `.ink`。内部文档结构继续复用现有页面、文本、图形与笔迹模型，但文件通过 VS Code 的 [CustomEditorProvider](https://code.visualstudio.com/api/extension-guides/custom-editors) 管理，不进入文本编辑器，也不逐次替换整个文件。旧 `.inkspace.json` 保留兼容编辑器。

## 文件结构与保存

文件以 12 字节 `INKSPACE3\0\r\n` 开头。每条记录包含 4 字节小端压缩长度、4 字节 CRC32 和压缩内容。内容使用 Node V8 二进制序列化，再以 DEFLATE level 1 压缩；基线记录保存整本模型，后续记录只保存编辑差异。笔迹中的 `(x,y,p)` 编码为 Float64 三元组，无舍入、简化或压力损失，其他字段原样保留。

增量涵盖新增/删除/替换笔迹、文本、图形、嵌入资源、页面列表、活动页和视图设置。Webview 比较不可变笔迹引用及轻量元数据，只传输修改部分；文件端异步压缩、按指定偏移追加，并 fsync 后确认保存。撤销也提交逆向增量。正常保存不重写基线。

日志超过 2,048 条记录或明显超过基线大小时，在保存停歇后执行原子基线压缩。坐标模型仍完全一致，历史记录不属于跨会话撤销承诺。格式为项目专用格式，读取器、写入器和转换器随源码分发；本版本二进制编辑器需要本地文件。

## 恢复与冲突

长度不完整的最后记录，或校验失败的最后增量，不影响其前面的完整记录；打开时提示恢复。下一次保存修复无效尾部。基线和中间记录的校验失败会报错，不静默丢弃后续内容。外部文件大小/修改时间变化会阻止覆盖，并保留画布草稿。VS Code 的备份、另存为与恢复接口也由自定义编辑器提供。

## 转换旧文件

```powershell
node scripts/convert-notebook.cjs 'D:\笔记.inkspace.json' 'D:\笔记.ink'
```

转换创建 `.backup-original` 原始备份，保留 JSON 原文件，拒绝覆盖已有目标或不匹配的备份，并在写入后逐字段验证全部内容以及原始文件未发生变化。之后使用 `.ink` 继续编辑，旧文件作为备份保留。

## 书写与验证

抬笔后的已完成墨迹使用独立保留层，下一笔只清除当前笔的实时层；Cairo 完成后局部提交，并移除对应保留区域。Raw Input 每批只读取一次视口和焦点信息，书写光标使用缓存边界。精确采样、压力和 Xournal++/Cairo 轮廓路线保持不变。

`npm test` 验证 Float64 精度、追加前缀、部分写入、CRC、尾部恢复及压缩；`npm run test:engine:binary` 在普通 VS Code 中验证 1,000 条已有笔迹、30 条连续新增笔迹、零整本 JSON 序列化、零整幅重绘、上一笔预览保持、自动保存、撤销、重开及页面保存。模拟原生输入用于重复验证，真实触控笔手感需要设备体验。
