# 0.9.0 工作台 DESIGN 落地（2026-10-07）

按已确认的 DESIGN 重建工作台结构和样式：39px 顶栏、224px 右侧上下文栏、65px 图形卡片、29px 底栏与 26px 公共悬浮条；采用灰色悬停框、浅蓝选中态、图标按钮和固定屏幕尺寸手柄。移除旧资源栏和媒体块顶部控件。普通鼠标默认编排，图形库与页面设置只进入临时面板；退出恢复之前的侧栏可见性。图形放在当前实际可见画布中心。

工作台只投影状态，公共命令表复用插入、悬浮条和右键操作，介质框只负责屏幕控件，不另设拖动监听。既有状态机、原生笔迹引擎、Cairo 缓存和增量文件保持独立。Markdown 编辑使用源码 AST 范围，就地片段保留周围预览；完整源码使用临时窗口。草稿不逐字提交历史，完成一次提交、Esc 取消，空新建框不留下文件对象；未编辑时保留 CRLF。

验证通过：npm test、test:workbench、test:ownership、test:blocks、test:interaction、test:text:caret 与普通 VS Code 的 test:engine:workbench。覆盖 DESIGN 尺寸/位置/颜色、深色主题、窄窗口、9 组固定控件倍率、27 组编辑框、30 次真实双击定位、100 次延迟栅格打点、焦点切换及二进制保存重开。截图来自生产页面的示例文档，未修改用户笔记；实体触控笔未由自动化操作。历史诊断中依赖旧顶部控件的测试不作为本版工作台验收。

# 0.8.0 交互核心重构（2026-10-07）

由统一输入路由与状态机决定手势所有权，选择保存稳定 ID，块框、点选、框选和连接读取同一几何。移除了文本、通用块、连接及画布入口中相互竞争的拖动监听；mxGraph 保留原生交互，使用明确委托与完成确认。实际模块及接入约束见 [交互架构](INTERACTION-ARCHITECTURE.md)。

新增验证覆盖相邻块的箭头覆盖、45 组文本/图片/HTML/小窗倍率边界、选择重排与对象恢复、拖动 Esc 取消、满 80 条历史时取消宽度调整、连接预览与提交坐标一致。保留存储格式与用户笔记，原有块交互、编辑、撤销、原生输入和保存回归继续运行。

验证通过：npm test（含严格类型检查）、test:ownership、test:blocks、test:interaction、test:text:mouse、test:text:caret、test:engine:binary 和 test:engine。VS Code 回归覆盖 100 次快速打点、1000 条笔迹上的连续书写/擦除，以及 202 个图形、21 条连接的持续拖动；书写、擦除与拖动期间均未重绘完整笔迹场景。真实触控笔硬件未由本轮自动化测试操作。

此轮没有重写笔迹引擎或全部文档操作。入口状态与历史效果仍在原模块；新核心集中决定输入归属，后续介质通过适配器复用公共交互。

# 0.7.1 整体检查与修正（2026-10-07）

范围覆盖块边界与坐标、鼠标/触控笔输入归属、编辑器切换、混合组合、复制引用、删除与撤销、PDF 加载与文件保存。依据代码检查和实际 Chromium / VS Code 回归，未修改用户笔记。

| 问题 | 修正与依据 |
| --- | --- |
| 新建框按占位文字宽度画边框，顶部条按排版宽度显示 | 编辑时采用完整 textarea 区域；边框与操作条复用尺寸，输入不再被占位文字裁剪 |
| 短文本预览操作条超过内容框，极窄文本按钮重叠 | 预览控件使用实际内容宽度，统一最小控件跨度；选择仍贴合文字，缩放不改变按钮屏幕尺寸 |
| 空新建框的宽度等控件触发先关闭编辑器，空块被删除，后续手势引用失效 | 明确区分结构操作与取消未使用输入；结构操作保留空块，画布入口防御过期目标 |
| 旧 PDF 组合使用资产引用，复用资产插入页面后原组合自动扩大 | 插入前规范化为原始页 ID 集合，新页面不进入原组合，历史引用不被修改 |
| 旧连线引用整份 PDF，复制页追加到同资产改变原端点范围 | 对被旧整份连接引用的资产保留独立容器，复制连线重映射到复制资产；现代单页连接继续复用资产 |
| PDF 校验遇到空资产或空页抛异常 | 返回无效；保留原文件与错误处理流程 |

主要验证：npm test、npm run test:blocks、npm run test:interaction、npm run test:text:mouse、npm run test:text:caret、npm run test:engine:binary。编辑边界覆盖 27 组倍率和内容组合；预览边界覆盖 15 组画布/块倍率；包含实际鼠标宽度拖动与撤销、复制连接、PDF 删除/导出及保存重开。

已知边界：完全重叠或包围端点的块可能不存在避障路径；真实设备的压力、延迟和手感仍需实际触控笔验证。入口 app.js 和宿主适配器仍较集中，后续可以继续拆分事件路由，但本轮保持存储格式和输入引擎不变。
