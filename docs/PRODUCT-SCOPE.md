# 产品范围与实现约束

2026-10-10 用户确认，以下决定优先于旧 DESIGN 和历史功能讨论。目标是在画布中书写、阅读和编排常见信息介质，当前只集中维护普通 Windows x64 VS Code 插件与独立 Ink Engine。

## 保留的基础

原始坐标和压力、快速打点不丢失、流畅导航和撤回、可靠增量保存、旧笔记及资产保护是必要能力。交互状态机分配唯一手势所有者；界面、内容渲染和文件存储不能分别争抢指针或键盘。扩展介质必须提供几何、内容能力、事务与资源释放契约。

## 文本与缩放

画布提供基本 Markdown/静态 HTML 源码编辑、列表、公式、代码展示、Tab 缩进及编辑会话内撤回。它不承担完整程序编辑器或完整网页运行环境。普通文件继续交给 VS Code 原生编辑器及其扩展；当前没有把嵌入块自动同步成外部源码文件的能力。

双击 Markdown 尝试进入对应源码段落；已有字符映射继续作为辅助，不承诺所有公式、嵌套标记及复杂 HTML 都能精确命中源码字符。复杂内容可以进入完整源码。临时编辑视口保持画布位置，完成一次提交，Esc 取消。

公共移动、选择、复制、组合、连线、右键和撤回入口统一，内部尺寸策略按介质区分：

| 介质 | 调整尺寸 | 内容行为 |
| --- | --- | --- |
| Markdown / HTML | 右侧柄调整宽度，属性栏独立调整字号 | 调宽重新换行；不显示整体缩放角柄 |
| 文本小窗 | 调宽及底边调整窗口高度 | 改变视口，字号保持不变 |
| 图片 / PDF / 图形 | 角柄等比缩放 | 保持介质比例和内容布局 |
| 混合选区 / 组合 | 公共角柄调整位置与尺寸 | 文本调宽、小窗调高；视觉介质等比缩放；文字字号不随之改变 |

所有控件保持固定屏幕大小，画布缩放不改变正文换行。旧文本块的整体 scale 保留，不自动重写其视觉尺寸。新调整使用宽度与可选 fontSize 字段；存储格式保持兼容。

## 输入设备

鼠标默认编排，触控笔默认画笔，两种输入分别记忆工具。属性栏“配置输入设备”决定顶栏和快捷键正在配置哪一种设备；实际进入画布使用对应指针时切回该设备。鼠标可以明确选择画笔、橡皮或图形绘制，没有额外启用开关。笔的 H 平移及工具二次按键返回在自己的设备状态中切换。中键、空格和触摸导航保持临时性。设备偏好保存在 VS Code webview 恢复状态，不产生笔记历史和磁盘内容修改。

## 画布与介质边界

新笔记默认连续白色画布及淡横线；A4 竖向/横向是可选布局，空白新 A4 画布保留首张纸，其他纸张按内容占用自动拓展。显式保存的旧 A4 布局保持不变。PDF 每页是独立块：连续布局在可见区域中心放置首项，后续项纵向排列；A4 布局保持纸张单元对齐。

内置图形聚焦笔记常用形状、标签、附着箭头和基本样式，不承诺完整 draw.io 功能和全部交互。继续复用 mxGraph，保留原稿导入/导出；当前未新增独立完整 draw.io 编辑窗口。

HTML 仅展示经过清理的静态内容，可使用隔离样式、表格和内嵌图片，脚本、表单和嵌入应用不运行。未来 XLSX 先考虑展示及外部编辑，不预设在画布里实现完整表格软件。

Theia、VSCodium 和独立桌面源码保留为历史实验，不继续承诺与主线同步的发布和功能。DESIGN 作为统一视觉和操作规范，可以根据实测调整，不要求逐像素复刻。
