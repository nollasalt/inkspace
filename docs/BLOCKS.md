# 介质块与统一操作

`canvas-blocks.js` 管理类型注册、选区扩展、组合、上下文菜单、HTML 插入与模型操作；`block-interaction.js` 管理鼠标命中、事件优先级、临时悬停控件和选区预览。它调用已有的笔迹、PDF、文本和 mxGraph 渲染器；不改变 Raw Input / Cairo 的采样与抗锯齿路线。

文本、图片与 HTML 使用 `notes` 条目，HTML 源码存于 `markdown` 字段以复用现有文本编辑与增量保存。类型注册描述可编辑性与渲染入口；HTML 经现有 DOMPurify 清理后在 Shadow DOM 渲染，采用固定宽度、随内容扩展高度的容器约束布局和样式。图形仍保存 mxGraph XML，PDF 保留原始字节与页面位置，笔迹保留原始压力样本。

选区快照统一描述 `strokes / notes / shapes / pdfs / diagram`，移动与缩放使用同一原点和比例。拖动仅更新缓存图层和 DOM 变换，完成时才修改模型、写入一条历史记录并触发原有延迟自动保存。PDF 操作替换资产对象，防止历史快照被后续页面位置修改污染；普通书写快照不额外复制 PDF。

组合存于画布的 `groups: [{id, members: [{kind, id}]}]`，使用稳定 ID 引用，而非数组下标。组合不会生成新的嵌套 DOM 或复制成员内容；点击任意成员扩展选区至全组。复制时分别重建所有介质 ID、图形 ID、组合 ID 与箭头附着目标，粘贴后连接对应新块。

非 DOM 块的连线入口共用一个鼠标悬停框，不随笔迹数量增加 DOM 节点。连接开始时为缺少 ID 的旧笔迹/图形分配稳定 ID；现有文本连接引用仍兼容，新介质采用带类型的引用。箭头保留明确的法向起终段和中间正交折线，避免自动路由吞掉边上的线段。

新增 XLSX 等介质时，应提供源码/资产保存、类型校验、渲染、尺寸、编辑入口和连接边界适配；移动、缩放、组合、菜单、复制与撤销复用该操作层。此版本没有实现 XLSX 读取或单元格编辑。现有 `.ink` 追加存储已能保存新块及组合字段，无需迁移用户笔记。

## 交互与几何边界

- `src/block-geometry.cjs`：无 DOM、无文档状态的世界坐标端点与正交路由；几何测试可直接运行。
- `src/note-connectors.js`：将原生图形终端和其他块引用适配为同一端点，管理连接手势、派生路由和兼容旧文件。预览不改模型；派生路由不独立增加撤销条目。
- `src/diagram-drag.js`：图形拖动复用 DOM，连接线用临时 SVG 克隆状态绘制；松开提交，取消恢复。选区框调用统一预览入口。
- `renderer.js`：按块更新文本，保持布局使用世界坐标尺寸；画布缩放只改变视图。鼠标指针的有效工具决定 CSS 输入层，避免编排与绘制状态不一致。

读取选区数量、组合成员及菜单状态用 `selectionEntries()` 浅引用；仅真实移动/缩放手势使用几何快照，避免悬停或点击复制大量笔迹采样。新增介质应实现 `connectionBounds()` 返回世界坐标边界，并复用统一连线，不增加另一套鼠标连接事件。
