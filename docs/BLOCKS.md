# 块模型与扩展边界

## 分层

- block-model.js：纯模型适配器，无 DOM、输入工具或宿主依赖。提供介质枚举、稳定 ID、PDF 单页读取/更新/删除、资产插入复用、片段复制及旧组合引用转换。
- canvas-blocks.js：组合、选区扩展、右键菜单和块操作；注册渲染入口。block-interaction.js：命中、手势优先级、临时悬停控件和选区预览。
- renderer.js、pdf.js、vscode/inline-text.js、mxGraph：各自的渲染、布局和编辑器。纯模型不读取渲染缓存；几何适配需要实际内容边界时，由渲染层提供世界坐标尺寸。
- src/block-geometry.cjs、src/obstacle-router.cjs：纯世界坐标端点、法向起终段、正交避障。src/note-connectors.js 负责把不同介质适配为端点；src/diagram-drag.js 负责图形拖动合成。
- VS Code 扩展与 Ink Engine 继续负责文件、校准、Raw Input 和 Cairo，不依赖块控件。

已有 app.js 仍持有画布状态和历史，宿主适配器仍负责界面装配；本次先抽出变化频繁的模型和路由边界，便于后续逐步缩减入口代码。

## 文本与 PDF

Markdown / HTML 是同一种文本块。notes 条目沿用 markdown 源文字段，format 为 md 或 html；省略格式时默认为 md，旧 kind:html 仍兼容。图片继续使用 kind:image。HTML 经过已有 DOMPurify 清理，在 Shadow DOM 内渲染隔离样式。右键切换类型只改变解释方式，保留源码和撤销历史。

PDF 文件是资产容器，保存原始 data 一次；每页拥有稳定 id、原稿 pageIndex 与 x/y/width/height。pdfPages 选区引用页 ID，不复制原始 bytes。删除原稿第一页后，剩余页面仍保留 pageIndex=1，渲染和导出读取原稿第二页。旧页面无 ID 时从资产 ID 和页序推导；第一次变更保留该 ID 和原稿索引。

页面修改和 PDF 插入均替换资产数组/对象，不修改历史引用。复制页到同一画布复用相同原稿资产，并创建新的页 ID；跨画布复制只包含选中页面所需的资产。存储格式沿用 .ink 增量记录，无需迁移用户笔记；旧 pdfs:assetId 组合及连接保持兼容。

## 操作和性能

选区统一描述 strokes / notes / shapes / pdfPages / diagram。读取数量、组合成员和菜单状态使用浅引用，仅移动/缩放手势创建几何快照。组合保存稳定的 kind/id，不生成嵌套 DOM；复制重新映射块、图形、组合和连接 ID。

文本宽度是排版尺寸，整体缩放是独立比例；画布缩放不修改排布。控件使用画布倍率与块倍率的倒数作为 CSS 单位，保持屏幕尺寸固定。拖动只变换已有图层，释放后一次提交历史和自动保存；不会逐点重建笔迹。

连线预览、最终显示和拖动共用路由。先检查普通正交路径，受阻时才按需加入障碍并执行带转弯代价的 A* 搜索；每个拖动帧统一收集障碍，不为每条边重复遍历文档。路由是派生数据，不增加单独撤销记录。互相重叠、完全包围端点的块可能没有不穿透的路径，此时保留可显示的原折线；这仍是路由边界。

## 新介质

新增 XLSX 等介质需要实现源码/资产存储、校验、渲染、世界坐标边界、编辑入口和模型适配。移动、缩放、组合、复制、菜单与撤销复用公共操作层；连接提供 connectionBounds() 并使用现有路由，避免另建输入事件链。当前未实现 XLSX 或单元格编辑。

npm run test:blocks 验证真实鼠标交互、固定尺寸控件、混合组合、PDF 页复制/撤销/导出、旧格式兼容及二进制重开；纯模型与路由测试无需 Electron。
