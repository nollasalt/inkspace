# 通用介质框与控件设计

状态：0.9.0 已实现公共屏幕控件层与悬浮操作条。本文能力契约保留后续介质扩展的设计目标；具体已实现范围及验证见 WORKBENCH-DESIGN.md 的实现记录。

目标是将现有的文本框、图片框、PDF 页面框和图形控件统一为 `MediaFrame`。框处理画布编排，内部的介质适配器处理内容显示和编辑。未来增加 XLSX 时接入能力和内容视图，不再复制一套文本框事件和 CSS。

## 已选外观：悬浮操作条

```text
          ↑ 连线入口（悬停）
             ┌──────────────┐
             │ MD  编辑 ▤ ⋯ │  悬浮操作条
             └──────────────┘
 ┌─────────────────────────────────────┐
 │                                     │
←│              内容视口              │→
 │                                     │
 └───────────────────═─────────────────□
          ↓                    整体缩放
```

采用用户确认的悬浮操作条：位于选区上方居中，与正文分离；26 屏幕像素高，图标 14–16 像素。类型标签、编辑/查看、显示方式切换与更多菜单按能力提供。选中使用细蓝色边框，普通悬停为灰色实线。图标与文字跟随 VS Code 主题，画布纸张保持白色。

悬浮条宽度取决于动作而非块宽度；窄块无需扩大正文来容纳按钮。操作条属于屏幕控件层，不将其尺寸算入块范围。正常位置为选区上方；空间不足则翻到下方，再按视口限制水平位置。最大宽度受视口约束，低频动作折叠到更多菜单。连线入口和尺寸柄拥有独立且不重叠的命中范围。

最多显示一条公共选区操作条。普通悬停只显示边框和四边连线入口，不为每个悬停块增加另一条操作条；选中后可用键盘和按钮访问全部动作。悬浮条位置调整不改变块几何、文档排版或纸张占用。完整工作台分类见 [WORKBENCH-DESIGN.md](WORKBENCH-DESIGN.md)。

## 三种尺寸操作必须分开

| 控件 | 含义 | 对内容的影响 | 提供给 |
| --- | --- | --- | --- |
| 右下角小方块 | 整体等比例缩放 | 同时改变内容显示尺寸，文字换行不变；控件屏幕大小不变 | 普通块和组合 |
| 右侧中点短竖柄 | 调整排版宽度 | 可以重新换行；字号不变 | Markdown、HTML 等可重新布局的介质 |
| 底边中点短横柄 | 调整窗口高度 | 改变可见区域；内容比例和源码不变 | 小窗模式下的可滚动介质 |

单个操作同时只出现一套控件。组合选择显示一套组合框与整体缩放柄，成员不再显示自己的缩放柄。文本编辑期间隐藏几何调整柄，保留操作条和完成按钮；退出编辑后恢复。

图像和 PDF 的宽高比默认锁定，用公共右下角柄整体缩放。图形通过同一个框提供移动和缩放，预览/提交委托给 mxGraph 适配器；不能同时显示 mxGraph 原生角柄和公共缩放柄。直线或笔迹的真实命中仍依据路径，不因为有矩形外框就把内部空白全部变为热点。

## 展示状态

| 状态 | 框 | 操作条与尺寸柄 | 连线入口 |
| --- | --- | --- | --- |
| 普通空闲 | 隐藏 | 隐藏 | 隐藏 |
| 小窗空闲 | 灰色细边框持续显示，表达裁剪范围 | 隐藏 | 隐藏 |
| 鼠标悬停 | 灰色实线 | 无操作条；尺寸柄在选中后显示 | 四边外侧箭头 |
| 已选中 | 蓝色细框 | 操作条与适用尺寸柄持续显示 | 悬停时显示 |
| 多选 / 组合 | 一套公共外框 | 一套公共操作条与整体缩放柄 | 明确悬停某个成员时使用该成员端点 |
| 编辑 / 内容操作 | 活动内容视口边框 | 完成、菜单；几何柄隐藏 | 隐藏 |
| 书写 / 擦除 / 图形绘制 | 保留小窗的静态边界 | 所有编排控件隐藏且不命中 | 隐藏 |

鼠标离开正文并移向操作条/箭头时，悬停会话仍保留。桥接区域仅用于维持显示，不接收按下事件；不能覆盖邻近内容的点选。动作开始后锁定所属块和控件，释放、取消或失焦前不重新选择所有者。

屏幕空间不足时，只调整控件摆放或隐藏低优先级控件；不能移动块、改变排版、触发纸张拓展。边框、按钮和连线入口的视觉尺寸固定为屏幕像素，缩放画布/块都不改变它们的大小。

## 鼠标与笔

编排工具下，鼠标点选块，按住正文或操作条可拖动；移动达到阈值才提交历史。双击可编辑介质进入内容编辑，第一次按下不清空选区或改变工具。鼠标中键始终临时平移，包括位于文本编辑器、HTML、小窗或 PDF 上时。

文本在双击后才能选取文字、定位光标；单击正文是编排。Markdown 优先编辑命中的源码片段，并提供完整源码入口；HTML 默认双击编辑源码，预览中的链接/按钮不抢占编排事件。按下时只建立待定拖动，超过阈值才捕获鼠标，保证双击还能命中正文。右键菜单可以进入“操作内容”会话，此时 HTML 链接、未来表格单元格或 PDF 文字选择由内容适配器处理；Esc 或操作条完成按钮退出。此会话只能有一个活动介质。

原来的 PDF 文字选择也接入内容会话，退出后回到原编排工具，不再为整个画布增加一套输入模式。图片和 PDF 双击使用完整查看入口，不创建文本框；查看窗口也由对应介质适配器提供。

触控笔按当前工具执行：画笔穿透全部框与内容写字，橡皮擦除笔迹，H 临时平移，编排工具使用公共选区。笔悬停不显示鼠标控件；触控笔不启动 HTML 内容点击或系统右键菜单。鼠标在画笔/橡皮/图形绘制工具下保留直接绘制行为。

编辑器继续独立接收键盘：Tab 缩进、文字选择、列表续写及本地 Ctrl+Z。画布快捷键只有在内容会话没有消费时才执行；编辑器关闭后再返回画布历史。不要依靠事件监听顺序决定优先级。

## 各介质的能力

| 介质 | 公共移动/缩放/复制/连线 | 双击 | 内容特有操作 |
| --- | --- | --- | --- |
| Markdown / HTML | 支持 | Markdown 就地源码片段 / HTML 完整源码 | 排版宽度、全显/小窗、窗口高度、格式切换 |
| 图片 | 支持 | 完整查看 | 原始尺寸、替换图片；裁剪可后续增加 |
| PDF 单页 | 支持，每页独立 | 完整查看这一页 | 选择原稿文字、页信息、删除当前页 |
| mxGraph 图形 | 支持 | 编辑标签 | 形状、填充、线条及标签属性 |
| 手绘 / 笔迹块 | 支持 | 无编辑能力时保持选中 | 颜色、笔宽等适用属性 |
| 未来 XLSX | 复用公共能力 | 编辑/操作单元格 | 工作表、显示区域、内容滚动；尚未实现 |

连接线是附着关系，不能按普通块缩放导致端点脱离。连接线复用选择、菜单、复制和删除，路由与端点编辑属于连接会话。移动连接的端点块时重算整条路径；取消或撤销恢复同一组端点引用。

## 菜单与侧栏

操作条 `⋯` 与右键菜单使用同一份命令表。公共项为编辑/打开（按能力）、复制、粘贴、组合/取消组合、层级、锁定、删除；格式、原始尺寸、PDF 原稿文字选择等放入介质项。缺少能力的项不显示，暂时不可用的动作才禁用。锁定为下一阶段新增能力，不在设计预览中伪装成已实现功能。

顶部保留编排、画笔、橡皮、统一图形入口，以及文本/图片/PDF 插入、页面设置和属性栏开关。图形库位于右侧栏，临时替换属性，默认在可见画布中心创建图形，插入后保持图形库打开；也可进入拖动绘制。两种方式生成相同图形块，删除独立手绘图形工具及重复入口。退出图形库后，侧栏显示当前块或工具属性；多选只显示公共属性或组合信息。编辑时不能自动跳回画笔设置。点击画笔等工具则显示工具属性；鼠标编排保持默认工具，中键移动不新增工具按钮，H 为笔平移快捷键。

显示方式按钮保持相同位置、同一入口，根据状态变换图标及提示；不分成两个开关。低频动作进入菜单，避免在框上堆叠全部属性。

## 几何契约

所有坐标操作依赖布局快照，不从各类框各自推导。

- `contentBounds`：内容在介质局部坐标中的范围。
- `frameBounds`：真实可见的内容视口，供边框、选择、框选、连接端点、纸张占用共同使用。
- `editorBounds`：暂时扩大的编辑窗口；不写回块的排版尺寸、缩放或世界位置。
- `chromeBounds`：操作条、尺寸柄和箭头的屏幕矩形，只用于控件命中，不进入 `frameBounds`。

全显文本可以自适应内容高度。新文本的宽度先自适应内容至默认排版上限；用户调整排版宽度后改为明确宽度，灰框立即随之改变，即使文字很短也能看见调整结果。自动宽度与明确宽度必须是模型中的两种策略，不能依靠不同 CSS 状态隐式切换。小窗使用明确可见宽高与独立滚动位置。

框选框是 `frameBounds` 的投影，不附加文字布局预留区、工具条、透明悬停区或隐藏滚动内容。实际笔迹和非矩形图形在点选时还提供精确命中形状；选中后的公共外框仍使用其范围。组合框是成员可见范围的并集。

编辑窗口可以临时扩大，但左上锚点不变，连接与纸张占用仍读取冻结的文档框；退出后恢复。滚动小窗只改变内部滚动，不影响外部端点与文档框。

## 接入现有架构

```text
InputRouter / InteractionMachine
             ↓
HitResolver：内容、选区、控件的统一命中结果
             ↓
MediaFrameController：move / scale / layout / viewport / connect / content
        ↙                                      ↘
MediaFrameView（公共屏幕控件层）         MediaAdapter（内容/预览/编辑）
             ↓                                  ↓
             GeometrySnapshot / 文档事务与历史
```

建议增加 `src/media/registry.ts`、`src/media/frame-controller.ts`、`src/media/frame-view.ts` 与 `src/media/geometry.ts`。适配器按能力注册，而非在公共框中反复判断 `kind==='image'`。

```ts
interface MediaCapabilities {
  move: boolean;
  scale: 'uniform' | 'none';
  edit: 'source' | 'label' | 'cells' | 'none';
  open: boolean;
  reflowWidth: boolean;
  scrollViewport: boolean;
  connect: boolean;
}

interface MediaAdapter {
  capabilities: MediaCapabilities;
  measureLayout(context: LayoutContext): LayoutSnapshot;
  hitContent(context: HitContext): boolean;
  previewTransform(context: TransformContext): void;
  commitTransform(context: TransformContext): void;
  enterContentSession(context: ContentContext): ContentSession;
  commands(context: CommandContext): MediaCommand[];
}
```

这些为设计契约，不是已添加的运行时接口。共享 ID、几何与事务，不要求所有介质改用同一种 DOM：文本继续使用现有编辑器，图形继续使用 mxGraph，PDF 保留缓存和原稿资产，笔迹保留独立 Ink Engine。

公共控件渲染在不随内容缩放的屏幕层。最多显示一个鼠标悬停框和一个公共选区框，避免为每条笔迹或每页 PDF 常驻完整按钮 DOM。布局测量仅在源码、排版、窗口尺寸、字体或资源加载变化时失效；移动/缩放读取快照和变换，不测量正文、不重建笔迹。

所有手势仍由现有状态机分配所有权。内容适配器可处理自身编辑与内部滚动，不能新增竞争的画布捕获链。命中优先级为当前会话、真实内容界面、平移/绘制策略、有效控件、内容精确命中、空白框选；邻近正文优先于其他块覆盖其上的箭头。

## 落地顺序与验收

1. 先提供公共控件层及几何快照，用文本和图片替换旧 `.note-*` 控件；同时移除旧控件，不能两套并行命中。
2. PDF 单页、图形和笔迹接入同一控件层，保留原渲染缓存，图形原生几何柄按会话禁用。
3. 统一命令表、侧栏能力属性和内容会话；再增加锁定等新能力。

验收包含：所有类型的点选/拖动/框选边界一致；相邻块不抢事件；小窗入口位置固定；连续二次缩放与宽度调整正常；控件在画布和块缩放时屏幕尺寸不变；新建短文本不挤压按钮；编辑保持锚点且文字撤销独立；笔可覆盖所有介质；图形/PDF/笔迹移动无内容重建；取消操作和每次完成操作保持原子历史。

设计预览用于体验点选、拖动、三类尺寸控件、双击编辑、小窗、连线及画笔穿透；它不连接实际文件、原生笔引擎或完整避障路由。复制/查看等需要生产适配器的动作，在预览中应明确说明能力范围。
