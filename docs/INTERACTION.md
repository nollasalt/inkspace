# 画布交互规则（0.9.0）

## 工具与输入

| 工具 | 鼠标和触控笔操作 |
| --- | --- |
| 画笔 P | 直接书写，可覆盖文本、图片、PDF、图形；鼠标无需开启开关 |
| 橡皮 E | 擦除笔迹，块控件不拦截 |
| 图形 D / S | 打开右侧图形库；选择居中插入或拖动绘制 |
| 编排 V | 点选、拖动块，空白处框选，选区右下角整体缩放 |
| 文本 T | 创建文本；双击已有文本编辑 |
| 触控笔移动 H | 从任意内容上拖动画布，再按 H 返回前一个工具 |
| PDF 文字 | 在 PDF 面板开启原稿文字选取，其他区域移动画布 |

鼠标中键在任意工具下临时移动画布，松开恢复所选工具。普通滚轮移动，Shift+滚轮横向移动，Ctrl+滚轮缩放；非绘制模式下文本小窗优先滚动正文。

选择画笔、橡皮、图形绘制时，鼠标直接绘制，不显示块控件、不触发双击编辑。按 V 后可编排内容。工具快捷键再次按下返回之前的工具。打开图形库只展示资源，保留当前工具；插入图形后明确切到编排，便于拖动、缩放和双击编辑标签。

## 所有块的公共操作

文本、图片、PDF 单页、笔迹、手绘及 mxGraph 图形统一支持点选移动、框选缩放、Ctrl+C / Ctrl+V、Delete、Ctrl+Z / Ctrl+Y。框选多个介质后 Ctrl+G 组合，点选任意成员选中整组；Ctrl+Shift+G 取消组合。组合不会合并源码或资产。

编排时双击空白创建文本，双击文本从对应源码位置编辑，双击图形编辑标签。图片、PDF 不创建文本编辑器。文本编辑暂时扩大为可滚动窗口，保留画布位置，退出恢复原视图；支持 Tab/Shift+Tab、列表续写和文本撤销。

文本、图片悬停显示灰色实线边框和四边圆形连线入口，选中后显示一条公共悬浮条。正文或条上的类型标签可拖动，右侧中点柄调整排版宽度，右下角等比例缩放内容；宽度与整体缩放独立。控件大小固定为屏幕像素，不随画布或块倍率改变。框选和预览操作条贴合可见内容；编辑时操作条、边框与输入区域一致。短文本也可重复调整排版宽度。

悬停块后点击边上的箭头，再点击目标块或目标边完成连接；Esc 取消。图形和普通块共用法向端点与正交避障路径，移动时整条路径更新。笔悬停不触发连线入口。重叠块、被完全包围的端点可能无法找到避障路径，详见块架构。

右键菜单提供类型、编辑、复制、粘贴、组合、取消组合、删除、新建文本与导入 HTML。输入框内保留文本操作菜单。Markdown / HTML 共用文本块，默认 Markdown，右键选择解释类型；切换保留原始源码。可拖入 HTML 文件或右键导入，支持静态 HTML、内联 CSS、表格和内嵌图片，脚本不执行；相对图片与外链样式不自动打包。

## PDF 与画布

PDF 每页是独立块，可选择、移动、缩放、删除、连接和组合。PDF 侧栏可定位单页或删除单页，文件旁的 × 删除全部页面。删除保留独立批注，Ctrl+Z 恢复；导出读取剩余原稿页。复制同一原稿的页面共享源文件 bytes。

一个 .ink 可含多个独立无限画布。底栏“画布”进入 VS Code 列表，支持添加、切换、重命名、排序、删除。各画布内 A4 纸张按内容拼接；空新画布仍显示一张纸。

## 界面与优先级

顶栏按操作分组，图形库与画笔、橡皮、图形绘制置于“绘制”分组；文本插入单独提供。PDF 与纸张是资源入口；侧栏只显示当前工具属性或所选资源，不重复增加入口。点击资源展开，再点收起，D 与顶栏图形库一致。侧栏开关在顶栏右侧。

1. 输入、搜索、图形标签编辑使用自己的键盘与菜单；触控笔可在文本编辑器上继续书写。
2. 中键和空格临时移动优先于块操作；绘制时块控件不接收手势。
3. 编排时先处理宽度、比例、连线等明确控件，再处理内容拖动和空白框选。
4. 点击选取不产生历史；超过 3 屏幕像素的拖动释放后产生一条历史。

npm run test:interaction 验证 45 组真实鼠标操作，以及中键移动、穿透绘制、资源入口和键盘归属。npm run test:blocks 验证不同倍率控件、组合、PDF 单页、连接、保存与撤销。

0.9.0 的悬浮条、右侧图形库、片段编辑和资源会话的完整规则见 [工作台设计与实现](WORKBENCH-DESIGN.md)。
