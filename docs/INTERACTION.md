# 画布交互规则（0.6.0）

## 块操作

文本、图片、HTML、PDF、笔迹、手绘图形及 mxGraph 图形使用同一套选区操作。鼠标点选后拖动移动，选区右下角缩放，Ctrl+C / Ctrl+V 复制粘贴，Delete 删除。文本、图片和 HTML 还保留原来的悬停控件，可独立调整宽度或比例。PDF 以整份导入文件为一个块，框选需要包含该文件全部页面。

框选多个介质后，Ctrl+G 或右键“组合”；点击组合任意成员选择全组，移动、缩放及复制以整组进行。Ctrl+Shift+G 或右键“取消组合”恢复独立块。组合不合并源码、图片或 PDF 字节，保留各自的编辑能力。双击文本编辑 Markdown，双击 HTML 编辑 HTML 源码，双击图形编辑标签；图片与 PDF 不创建文本编辑器。

鼠标悬停显示连线入口，点击边上的箭头后再点击目标块完成连接；Esc 取消。箭头出边、入边都与对应边垂直，移动缩放后跟随块。普通笔迹和手绘图形在实际图形处命中；非 DOM 介质共用一个临时控件框。触控笔不触发悬停连线控件。

画布右键提供编辑、复制、粘贴、组合、取消组合、删除、新建文本、HTML 与导入 HTML；输入框内右键仍是原来的文本操作。鼠标右键不再拖动画布，中键继续临时移动。

顶栏“HTML”导入 `.html` / `.htm`，也可拖入文件或粘贴剪贴板中的 HTML。当前支持静态 HTML、内联 CSS、表格和内嵌图片；脚本、表单控件和内嵌网页不执行，文件相对图片及外链样式不会自动打包。需要保存图片时使用含内嵌图片的 HTML，或单独粘贴图片块。

`npm run test:blocks` 验证真实鼠标编辑 HTML、混合介质组合拖动/缩放、控件间隙可达、复制连接目标、PDF 原始字节、右键菜单和 `.ink` 保存重开。

一个 `.ink` 可包含多个独立无限画布，每个画布中的 A4 纸张按内容自动拼接。底栏“画布”进入 VS Code 画布列表，支持新建、切换、重命名、排序及删除。

## 工具与输入

| 工具 | 触控笔 | 鼠标 |
| --- | --- | --- |
| 画笔 / 橡皮 | 书写 / 删除笔迹，可覆盖文本、图片和图形 | 默认点击选取、拖动对象，空白处框选；开启“鼠标也使用画笔 / 橡皮”后绘制 / 擦除 |
| 移动（H） | 在任意内容上拖动画布 | 对象控件可操作，其他区域拖动画布 |
| 编排 | 框选、移动选区、缩放选区 | 点击选取对象、拖动对象、空白处框选 |
| 文本 | 空白处创建文本 | 点击空白创建文本，双击文本从点击位置编辑 |
| 绘制 | 绘制矩形、椭圆、直线、箭头 | 相同；对象控件隐藏，绘制穿过文本、图片、图形 |

| PDF 文字 | 选择 PDF 原文 | 选择 PDF 原文；其他区域移动画布，不编辑对象 |

鼠标默认左键编排对象，中键在任何工具、任何笔记介质上拖动画布，松开即恢复原操作。H 切换到触控笔移动，再按 H 返回原工具；顶栏不额外增加移动按钮。打开图形库不会切换当前触控笔工具；鼠标在默认编排操作下使用 mxGraph 原生拖动、缩放、连接、文本编辑。工具按钮和快捷键再次选择同一工具时返回前一个工具；若只是查看资源，点击当前工具回到其属性。

## 优先级

1. 搜索、文本输入、图形标签编辑与缩放按钮独立处理输入。触控笔仍可在正在编辑的文本框上书写。
2. 非绘制模式下，鼠标使用对象的拖动、宽度、缩放、小窗、连线控件。中键临时移动优先于对象控件，正在编辑的文本框也可中键拖动画布。
3. 绘制模式不触发对象悬停、连线或双击编辑。触控笔悬停不显示鼠标控件。
4. 空白处和内容区域按输入工具处理，点击选取不产生撤销记录；超过 3 屏幕像素的对象拖动产生一条撤销记录。

普通滚轮移动画布，Shift+滚轮横向移动，Ctrl+滚轮缩放。小窗文本在非绘制模式下优先滚动正文；Ctrl+滚轮仍缩放画布。

## 界面分类

顶栏集中提供编排、书写、插入操作，以及图形、PDF、纸张资源入口。侧栏只是顶栏选择的内容区，不重复提供资源入口；展开 / 收起按钮位于顶栏右侧。资源入口统一采用点击展开、再次点击收起，切换资源时直接显示目标内容。D 与顶栏图形入口使用同一操作，不切换工具；PDF 原文选取在 PDF 面板内开启。工具用实色高亮，资源用下划线表示展开状态。切换工具返回对应属性，已收起的侧栏保持收起。

`npm run test:interaction` 使用真实 Chromium 鼠标事件验证文本、文本小窗、图片、手绘图形、mxGraph 图形的选取、拖动、移动、穿透绘制，覆盖 55 组操作，检查工具保持、撤销次数、搜索输入、统一资源入口以及跨工具中键移动。原生输入、保存和文本控件另由现有 VS Code / Electron 测试覆盖。
