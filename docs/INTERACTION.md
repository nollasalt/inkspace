# 画布交互规则（0.5.39）

一个 `.ink` 是一个无限画布；纸张按内容自动拼接。旧文件中的多个独立画布保留兼容导航，不删除或合并原有内容。

## 工具与输入

| 工具 | 触控笔 | 鼠标 |
| --- | --- | --- |
| 画笔 / 橡皮 | 书写 / 删除笔迹，可覆盖文本、图片和图形 | 默认点击选取、拖动对象，空白处框选；开启“鼠标也使用画笔 / 橡皮”后绘制 / 擦除 |
| 编排 | 框选、移动选区、缩放选区 | 点击选取对象、拖动对象、空白处框选 |
| 文本 | 空白处创建文本 | 点击空白创建文本，双击文本从点击位置编辑 |
| 绘制 | 绘制矩形、椭圆、直线、箭头 | 相同；对象控件隐藏，绘制穿过文本、图片、图形 |

| PDF 文字 | 选择 PDF 原文 | 选择 PDF 原文；其他区域移动画布，不编辑对象 |

鼠标默认左键编排对象，中键在任何工具、任何笔记介质上拖动画布，松开即恢复原操作。没有独立移动工具和 H 快捷键。打开图形库不会切换当前触控笔工具；鼠标在默认编排操作下使用 mxGraph 原生拖动、缩放、连接、文本编辑。工具按钮和快捷键再次选择同一工具时返回前一个工具；若只是查看资源，点击当前工具回到其属性。

## 优先级

1. 搜索、文本输入、图形标签编辑与缩放按钮独立处理输入。触控笔仍可在正在编辑的文本框上书写。
2. 非绘制模式下，鼠标使用对象的拖动、宽度、缩放、小窗、连线控件。中键临时移动优先于对象控件，正在编辑的文本框也可中键拖动画布。
3. 绘制模式不触发对象悬停、连线或双击编辑。触控笔悬停不显示鼠标控件。
4. 空白处和内容区域按输入工具处理，点击选取不产生撤销记录；超过 3 屏幕像素的对象拖动产生一条撤销记录。

普通滚轮移动画布，Shift+滚轮横向移动，Ctrl+滚轮缩放。小窗文本在非绘制模式下优先滚动正文；Ctrl+滚轮仍缩放画布。

## 界面分类

顶栏集中提供编排、书写、插入操作，以及图形、PDF、纸张资源入口。侧栏只是顶栏选择的内容区，不重复提供资源入口；展开 / 收起按钮位于顶栏右侧。资源入口统一采用点击展开、再次点击收起，切换资源时直接显示目标内容。D 与顶栏图形入口使用同一操作，不切换工具；PDF 原文选取在 PDF 面板内开启。工具用实色高亮，资源用下划线表示展开状态。切换工具返回对应属性，已收起的侧栏保持收起。

`npm run test:interaction` 使用真实 Chromium 鼠标事件验证文本、文本小窗、图片、手绘图形、mxGraph 图形的选取、拖动、移动、穿透绘制，覆盖 55 组操作，检查工具保持、撤销次数、搜索输入、统一资源入口以及跨工具中键移动。原生输入、保存和文本控件另由现有 VS Code / Electron 测试覆盖。
