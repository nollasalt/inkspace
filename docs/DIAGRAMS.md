# 鼠标图形编辑

从左侧图形库点击或拖入矩形、圆角矩形、椭圆、菱形、箭头和直线；点击“绘图”或按 D 切换图形工具。鼠标点击图形会进入绘图模式；在图形中央拖动移动，仅从边界连接点拖出连线；拖动边角手柄缩放，双击在图形内输入文字。再次按 D 返回之前的工具。

文字支持 Markdown 和 LaTeX，例如 `**标题**`、`$x^2$`、`$\frac{a}{b}$`。公式使用项目已有的离线 KaTeX 渲染。触控笔仍由独立 Ink Engine/Cairo 处理，可直接在图形上书写。

从图形边缘的连接点拖到另一个图形，或按住 Ctrl 选中两个图形后点击“连接箭头”。连接线会随端点图形移动、缩放。选中的图形支持 Ctrl+C / Ctrl+V；复制到新页面后，连接箭头指向复制的新图形。点击空白取消选择；侧栏可调整颜色、线宽和上下层级，方向键微调位置，Shift+方向键移动 10 个单位。Delete 删除，Ctrl+Z 撤销，Ctrl+Y 重做，自动保存。

“导入 draw.io”读取 `.drawio` / `.xml` 的第一个页面，支持标准压缩和未压缩模型。“导出 draw.io”输出未压缩 mxfile，可在 draw.io 中继续编辑。当前支持标准 mxCell/mxGeometry 模型；自定义插件对象和 draw.io 专有模板不在此版本的导入范围内。

## 实现与上游

直接复用 [mxGraph 4.2.2](https://github.com/jgraph/mxgraph)，这是 draw.io 使用的图形编辑基础。没有复制完整 draw.io Web 应用；Inkspace 的工具栏、笔迹层、文件管理和保存仍由本项目提供。mxGraph 上游已归档，本项目固定版本，禁止 XML 代码求值，仅允许标准模型节点，并限制导入大小。依赖、图片及许可均本地打包。

本次 Apache-2.0 依赖与原 GPL-2.0-or-later 代码的组合以 GPL-3.0-or-later 发布。旧许可证和上游 Apache 许可证保留在 `docs/licenses`。对应源码包包含完整 mxGraph 模块源代码。

## 纸张与 PDF

画布自动按 A4 纸张拼接，页面设置只保留竖向/横向。旧无限画布文件以竖向 A4 显示，原有内容坐标保留。空白区域维持灰色，内容占用的纸张显示为白色。

导入 PDF 时，以视口中心所在的 A4 页面为起点；每页等比适配并居中，后续页沿竖向 A4 边界排列。横向、竖向与非 A4 原稿均可适配，文字选择层与批注导出使用相同缩放。

撤销在画布本地立即执行，再按自动保存节奏写入文件。相邻图形编辑使用 mxGraph 增量撤销，原生笔迹只重绘受影响区域。历史版本的直接路径笔迹保留完整重绘，以维持原始抗锯齿效果。

## 删除 PDF 与拖动吸附

左侧栏的 **PDF** 列表显示当前笔记页的 PDF 文件，点击文件名右侧的 **×** 删除该 PDF 的所有页面；也可通过“文件 → 管理 / 删除 PDF…”定位到列表。删除保留独立的笔迹、图形及文字批注，Ctrl+Z 可恢复原始 PDF。

图形拖动到纸张边缘附近时，左右边、上下边会自动吸附对应 A4 边界，角点可同时对齐；按住 Alt 临时关闭吸附。坐标保留小数，因此无需将 A4 改成整数像素尺寸。拖动使用现有图层位移和按帧更新的连接线预览，松开鼠标后才提交保存和撤销记录。
